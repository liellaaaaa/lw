# 01-AI消化笔记

**这里不是摘要区。**

把一份原始资料交给 AI，产出的是"对我有用的消化"，而不是"这篇文章讲了什么"的缩写版。

## 每篇消化笔记必须回答

> 这份材料对我有什么用？

如果一篇笔记答不上这个问题，它就不该出现在这里。

## 推荐结构

- **一句话结论**：这份材料最值得记住的一点。
- **原始资料讲了什么**：简要还原，2–5 句即可，不展开。
- **对我有什么启发**：联系我的学习、创作或工作，说出具体用处。
- **可以变成什么输出**：文章 / 知乎回答 / 小红书图文 / 视频脚本 / 学习笔记，列出可能的落点。
- **下一步动作**：具体要做的一件事（比如"周一写成一篇小红书"）。

## 配合工具

消化用的提示词放在 `02-方法库与提示词/原始资料消化提示词.md`，新资料进来直接调用即可。
