# 02-方法库与提示词

这里存放**可复用**的提示词与方法，让"原始资料 → 消化笔记 → 输出成果"的动作越来越稳定、可重复。

所有提示词均按**肖聪本人**的情况个性化（AI 技术专员 / 宏昊AI助手 / ai-sales-coach / DISC SC 型）。

## 提示词清单

| 文件 | 用途 | 输入 → 输出 |
| --- | --- | --- |
| `原始资料消化提示词.md` | 通用消化入口 | `00-原始资料/` 任意材料 → `01-AI消化笔记/` |
| `读书笔记消化提示词.md` | 读书材料消化 | 读书摘录 / 整本书 → `01-AI消化笔记/`（含 个人收获/过往错点/今后改进） |
| `周报日报消化提示词.md` | 工作记录消化 | 周报 / 日报 → `01-AI消化笔记/`（也可喂 `04-复盘/`） |
| `项目梳理提示词.md` | 项目资料消化 | 宏昊AI助手 / ai-sales-coach 资料 → `01-AI消化笔记/` |
| `选题与输出提示词.md` | 产出具体内容 | `01-AI消化笔记/` → `03-输出成果/`（附输出回流卡） |

## 用法

1. 新资料进 `00-原始资料/` 后，按材料类型选对应提示词，让 AI 生成消化笔记到 `01-AI消化笔记/`。
2. 消化笔记积累后，用 `选题与输出提示词.md` 产出 `03-输出成果/`。
3. 自己沉淀的新方法，也写进本目录，逐步长成个人方法库。

`模板/` 子目录存放旧版 Obsidian 笔记模板，可作为新模板的参考。
