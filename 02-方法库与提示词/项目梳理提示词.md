# 项目梳理提示词（肖聪 · 个性化版）

> 用途：`00-原始资料/` 下与「宏昊AI助手」各模块、或 ai-sales-coach 相关的项目资料 / 文档 / 对话 → `01-AI消化笔记/`。
> 用法：把整段发给 AI，指定具体项目或模块。

---

## 指令

读取指定项目资料，生成项目消化笔记，**必须回答"这个项目材料对我有什么用"**。结构：

1. **一句话结论**（这个项目 / 模块当前状态与价值）
2. **资料讲了什么**（模块功能 / 进度 / 问题）
3. **核心拆解**（技术点 / 用户场景 / 可复用组件）
4. **对我的工作有什么启发**（如何反哺宏昊AI助手或 ai-sales-coach）
5. **可以变成什么输出**（需求文档 / 复盘 / 对外文章 / 教程）
6. **下一步动作**

注意（沿用旧库纪律）：
- **不要臆测项目间关系**；只连真实存在且你正在做的项目（宏昊AI助手各助手、ai-sales-coach）。
- 不把 4–6 月前期记录错链到 ai-sales-coach 的"悠久历史"里——肖聪是 2026-07 才接手该项目。
