# AI 自生长知识库（简略版）

## 这个知识库是干什么的

让我能把资料放进去，让 AI 帮我消化，再产出文章、学习笔记或选题。

它是一个"会自己长大"的系统：你只负责把材料丢进来，消化、提炼、产出和复盘都交给固定的流程跑。目的不是收藏，而是让每一份资料都能回流成你的能力和作品。

## 五个文件夹分别放什么

| 文件夹 | 放什么 |
| --- | --- |
| `00-原始资料/` | 原始素材：文章、视频逐字稿、课程笔记、读书摘录、聊天记录、灵感、网页摘录。不用先整理，先放进来。 |
| `01-AI消化笔记/` | AI 帮你消化的笔记。不是摘要区，每篇必须回答"这份材料对我有什么用"。 |
| `02-方法库与提示词/` | 可复用的提示词、方法、模板。让消化动作越来越稳定、可重复。 |
| `03-输出成果/` | 文章大纲、文章初稿、知乎回答、小红书图文、视频脚本、学习总结。每份成果都要附"输出回流卡"。 |
| `04-复盘/` | 每周记录一次：资料进来了吗、消化了吗、产出什么了、哪个环节最有用、下周只推进哪三件事。 |

## 最小工作流

```
00-原始资料/
  → 01-AI消化笔记/
    → 03-输出成果/
      → 04-复盘/
```

1. 把材料丢进 `00-原始资料/`
2. 让 AI 生成一篇消化笔记到 `01-AI消化笔记/`
3. 基于消化笔记，产出文章 / 笔记 / 选题到 `03-输出成果/`
4. 周末在 `04-复盘/` 记录一次，完成闭环

## 一句话原则

**收藏只是入口，回流才是知识库开始自生长的地方。**

## 提醒

不要一开始追求完美分类，先跑通一份真实材料。
