# 个人知识库（Personal Knowledge Base）

> 管理者：肖聪（AI 技术专员） · 载体：Obsidian · 根目录：`e:/lw`

## 1. 这是什么

一个以**个人成长**为核心的长期知识库。把日常工作记录、读书思考、项目经验、自我认知沉淀为可检索、可复盘的"个人资产"。不对外发布，主要服务本人复盘与 AI 辅助整理。

## 2. 适用对象

- **本人**：日常记录、复盘、读书分享、沉淀方法论。
- **AI 助手**：按 [`AGENTS.md`](AGENTS.md) 与 `.codebuddy/skills/kb-ingest` 规范录入与整理。

## 5. 工具依赖

- **Obsidian**：用于查看与导航，依赖其 `[[wikilink]]` 双链与 `---` frontmatter 语法。
- 纯文本 Markdown，无其他运行时依赖。
- 不依赖特定主题或插件（双链为内置功能）。

## 6. 如何录入新内容

任何新文件 / 内容交给 AI 整理时，遵循 `.codebuddy/skills/kb-ingest` 规范，流程为：

1. **确认载体工具**（当前：Obsidian）→ 2. **识别类型、建议归入目录** →
3. **反问澄清**（是否重排、关联哪些真实条目、时间粒度、字段名）→
4. **对齐目标目录现有格式** → 5. **执行录入** → 6. **回执**。

智能体层面的硬约束见 [`AGENTS.md`](AGENTS.md)。

### 已确认的统一约定
- 时间只写**年月日**，不写时分。
- 岗位统一写 **AI 技术专员**。
- 读书笔记字段：`个人收获 / 过往错点 / 今后改进`。
- 读书笔记**不**反向链接周报 / 日报（2026-07 起取消）。

## 7. 维护约定

- **索引手写维护**：`欢迎.md` 与各 `索引.md` 由人工 / AI 在新增内容后同步更新，保持入口可达。
- **命名一致**：周报 `周报-M.D-D.M.md`、日报 `日报-YYYY-MM-DD.md`、读书笔记 `书名.md`、项目 `仓库名.md`。
- **原始素材归档**：未整理源文件放 `raw/`，整理后入 `wiki/`，不在 `wiki/` 直接堆原始文件。
