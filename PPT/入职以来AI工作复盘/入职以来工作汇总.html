工作框架总览

INTERNAL / EXTERNAL

内部（公司内）

  1. 需求研判 · 方案设计 · 跨部门对接——从"接需求"前移为"判需求、出方案、对接领导拍板、推动执行与迁移"。
  2. 自研应用交付（建应用路径）——客户端/前端/前后端程序：船务 T/T 助手、采购分析、对账单、退税审单、数据脱敏。
  3. Skill 抽象与复用（提效路径）——复现场景、抽象输入输出为可复用 Skill，提效或赋能业务自建。
  4. 培训与推广——技术（编程/前后端/Skill）+ 非技术（WorkBuddy/千问/minimax code/读书）；含采纳驱动与宣推。

外部（供应商）

  1. 找供应商实现固定需求（线索获取等）——非重点，不展开。
  2. 宏昊 AI 助手平台（供应商）——验收运营与质量闭环、知识库内容运营监督、权限与文档管理中心、各智能体、培训助手、内容生成助手（视频/图片）。
岗位本质：AI 技术专员 = 出方案 / 判断方案 / 对接领导一键 / 推动执行与迁移，不是运营。本报告据此把"方案设计、验收监督、推广采纳"单列，不被"执行"吞没。

三、自研应用交付（建应用路径）

APPS DELIVERED
采购分析助手ProcurementAnalysis采购部 · 入职首个项目

采购部原料价格监控与分析平台。原靠人工盯盘 + Excel，价格异常往往事后才发现。

  • 项目周期 61 天（04-30 → 06-30），交付周期 29 天
  • 代码迭代 51 条；覆盖有效产品 61 个
  • 管理价格数据 15,227 条（基准价 5,673 + 详细报价 9,554）
  • 功能模块 7 个：看板/报表/供应商看板/预警/操作日志/认证/行为追踪
  • 6 月重大升级 4 项（供应商看板/自动刷新/架构重构/行为追踪）
价值：把价格监控系统化——看板看趋势、预警推异常、供应商看板做横向对比；让"拍脑袋比价"变"看数据决策"。当前维护模式（最后推送 07-30）。
外贸 T/T 协议自动化shipping-helper船务部 · 交付量最大

船务部 TT 协议全流程提效工具。原靠人工逐项填单，易错、耗时长。

  • 首版周期 26 天（05-28 → 06-22）；前置文档 14 份（PRD×4/测试×1/设计×6/阶段×3）
  • 代码迭代 44 条；3 个 Phase 全打通（数据解析/单证生成/报关）
  • 支持单证 4 类（Booking/LOI/MSDS/报关资料）；HS 编码 389 条；13 种桶型 + 2 托盘 + 3 运输模式
  • 7 月深化：PI 解析接入 DeepSeek（失败降级 Regex）+ 报关资料自动化
  • 当前进度 95%+（07-24 培训完成，3 项待定）
  • MSDS 中英文双语生成：内嵌能力（非独立工具），中文进、英文出免翻译
价值：录入基础数据即生成 4 类单证、自动算包装与 HS 编码；PI 解析 + 报关自动化把"人填"变"系统出"；MSDS 双语免翻译、免乱码。
数据脱敏工具Data_masking财务部 · .exe 打包

财务部等外发数据含身份证/银行卡/手机等敏感字段，手工脱敏易漏、易违规。

  • 版本 v1.1.0（07-10）→ v1.2.0（08-07·收尾）
  • 脱敏方法 12 种（v1.2.0 新增金额保留格式）；支持编码 4 种
  • 技术栈 Streamlit + pandas + openpyxl + Faker + cryptography + PyInstaller
  • 07-28 移交财务部；08-07 起重激活为长期优化项目
价值：一键合规脱敏批量处理，支持 4 种编码，防数据泄露合规事故；移交财务自主使用。
对账单（纯前端）纯 HTML 单页财务部 · 零部署

财务部对账场景轻量纯前端工具，内部"建应用"路径中"纯前端"形态代表。

  • 实现形态：纯 HTML 单页，无后端、无数据库，浏览器直接打开即用
  • 交付状态：✅ 已追加交付财务部
  • 轻量纯前端，无独立代码迭代条目统计
价值：把对账逻辑网页化，财务自助填写即生成规范对账单，零部署、即开即用；是"小需求、快交付"典型。
退税资料审核Tax_check财务部 · 08-01 交付运营

财务部出口退税「资料齐全性体检」工具，08-01 打包交付运营（收尾并入）。

  • 架构演进：纯静态 HTML+JS → FastAPI（08-01 迁移）
  • 技术栈 FastAPI + RapidOCR + pdfplumber/pypdf + PyInstaller 打包 .exe
  • 数据合规：本地 .exe 运行，数据不出境
  • 功能：OCR 识别+重命名、条款矩阵判定、一键导出规范 ZIP；LLM 智能审核(P2)待规划
价值：外贸退税命门是"资料齐全且规范"（16+ 种单据、按价格条款不同必传不同）。工具把"资料体检"自动化——OCR+重命名、条款矩阵判定、一键导出，把财务从"肉眼翻几百文件找缺什么"变"工具 1 分钟告诉你还差哪张单"。

四、Skill 抽象与复用（提效路径 · 3 个）

SKILLS

① tax-refund-audit（退税审单 Skill）

  • 交付对象：财务部
  • 形态：可复用 Skill（退税审单工作流抽象）
  • 与应用关系：与 Tax_check 应用互补——应用做 OCR+条款矩阵"体检"，Skill 做审单流程复用与下沉
  • 状态：✅ 已交付财务使用

价值：把高频强规则工作流抽象为 Skill，财务直接复用，降低对专人/专工具依赖——"工具 + 技能"双交付。

② daily-commodity-price-scraper（价格爬取 Skill）

  • 定位：钩子（hook）——培养采购部门自主制作 Skill 的能力
  • 交付对象：采购部（赋能，非代劳）
  • 后续：仍回采购部门培训，巩固"自建 Skill"能力
  • 理念：复现场景 → 抽象复用 → 赋能业务自建

价值：不止"帮采购抓价格"，更以价格爬取 Skill 为教具让采购部学会自己造 Skill——把提效能力留在业务侧，AI 小组退后为赋能与把关角色。
