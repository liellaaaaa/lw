# DESIGN.md — 入职以来 AI 应用交付复盘（月度经营分析会）

> 视觉来源：用户提供的模板 `月度经营分析会汇报模版：PBC执行进度.pptx`（企业蓝、表格密集型）。
> 用户显式指令：**严格沿用模板格式与配色**；PBC 专属表述（得分/权重/同比）因 8 月才启用 PBC，按实际工作内容增删。
> 故本项目以通用设计法则为底，配色/字体/版式直接取自模板解析结果（见下「模板实测色板」），用户指令优先于任何分支常量。

## 2. 模板实测色板（本项目唯一色彩池）
| 角色 | hex | 用途 |
| --- | --- | --- |
| 主色 PRIMARY | `#052B7C` | 章节标题字、目录标题、汇报人标签、封面深蓝 |
| 辅色 BRIGHT | `#4472C4` | 封面/封底横幅底、强调分隔线、标题色块 |
| 目录蓝 HEADER | `#2F5597` | 目录「目录 / Contents」 |
| 表头浅蓝 | `#DAE3F3` | 表格表头行底色、权重列外的浅蓝填充 |
| 权重浅灰 | `#F2F2F2` / `#E7E6E6` | 表格「权重」列、斑马纹 |
| 合计浅橙 | `#FCE4D6` | 合计/小计行底色 |
| 警示红 | `#FF0000` | 注意点/风险提示（仅少量） |
| 文本 | `#1A1A1A` | 正文 |
| 背景 | `#FFFFFF` | 页面底 |

**面积分配**：主色（横幅/标题）≤ 25%；辅色/浅蓝（表头、色块）≤ 30%；强调红 ≤ 5%；中性（文本/边框/白底）剩余。
**Hero 页**（封面/概览/验收/封底）强调色可到 15–20%（蓝幅铺满）。

## 3. 字体系统
- 标题/正文：`微软雅黑`（Microsoft YaHei）；数字/英文：`Arial`。
- 字号阶梯：封面主标题 52 / 章节标题 30 / 卡片小标题 22 / 正文 17 / 表头 16 / 表体 15 / 页码 14。
- 巨型数字（锚点）：44–72 bold，必须与正文不同字重。

## 4. 版式规范（复刻模板）
- 封面：通栏 BRIGHT 蓝幅居中偏下，白字标题；上方小标语「助力企业利润持续增长」(PRIMARY)；右下「- 机密受控 -」(楷体感，用 PRIMARY 替代)；部门/汇报人字段 PRIMARY 16。
- 目录：左「目录 / Contents」(HEADER 30)，右 6 行章节列表（黑 24 bold），中竖线分隔。
- 内容页：A 区左上章节标题（如「二、自研应用交付总览」）；B 区满宽表格（表头 `#DAE3F3`、权重列灰、合计行橙）或卡片组；底部可加「注意点」红字提示。
- 封底：通栏 BRIGHT 蓝幅白字「汇报完毕！/ 没有绩效，一切无效」。

## 5. 配图
- 本复盘为数据/交付盘点，无具象摄影需求；不使用 ImageGen。
- 视觉锚点以**巨型数字 + 色块**实现（概览页、验收页），符合模板克制商务调性。
- 不使用 200×70 装饰小贴片。
