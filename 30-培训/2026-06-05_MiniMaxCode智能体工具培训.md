# MiniMax Code 智能体工具培训分享

**日期**：2026-06-05 ｜ **分享人**：肖聪（AI技术专员） ｜ **性质**：智能体工具（MiniMax Code）培训 / 分享
**来源**：桌面导出《团队与培训/260605AI工具推荐》（ppt/minimax-code-intro.url 等）

## 一、培训目标
围绕 **MiniMax Code（智能体编程工具）** 展开，帮助听众建立"智能体工具能做什么、怎么用"的认知。关键做法：不只用 PPT 干讲，而是**刻意准备多类型材料，从多个维度立体说明智能体工具**——避免单一角度讲不清、听众无感。

## 二、多维度说明智能体工具（本次分享的框架）
| 维度 | 材料 | 说明什么 |
|---|---|---|
| HTML 分析 | `html/` 幻灯片 | 工具的**产出形态**——以网页/HTML 做分析演示，直观看到 AI 能产出什么 |
| PPT / 调研报告 | `ppt/minimax-code-intro` + 《珠三角纺织印染助剂市场调研报告》 | 工具**本身介绍** + 在**业务分析场景**的产出能力（调研/分析类任务） |
| 个人分析 | `个人介绍/肖聪-职场风格` | **人 + 工具**的协作关系——工具定位与个人能力互补 |
| 降本增效 | `降本增效/降本增效分析报告` | 从**成本与效率**视角展示智能体工具的**业务价值** |

> 沉淀的方法论：**讲智能体工具不要只做 demo**。要让人真正理解，需从"产出形态 / 业务场景 / 人与工具关系 / 成本效率"多个维度同时切入。

## 三、调研报告维度的关键知识（作为样例素材的核心发现）
智能体工具在"市场/业务分析"类任务上的产出能力，可用这份真实调研佐证：
- 全国印染助剂市场 2024 年约 **455 亿元**；珠三角估算 **90–115 亿元/年**（按产能占比推算，无权威单独统计）。
- 传化智联 + 德美化工合计市占 **<15%**，行业高度分散，整合空间大。
- 淡季珠三角印染厂开机率 **30–40%**（中山/佛山实地调研），低于江浙 20–30pct；七成为亏损临界点。
- 已逐户核实 **74 家**珠三角印染企业名录（工信部准入名单 + 政府公告）。
- 政策窗口期（2023–2025）倒逼绿色转型：含氟防水剂（C8/C6）全面替代，无氟方案成唯一出路；EU CBAM / REACH SVHC / PFAS 加码。

## 四、对宏昊化工的落地启示（来自调研维度）
- 聚焦佛山根据地（三水大塘/西樵/杏坛）→ 直销 + 技术服务网络。
- 切入无氟防水剂 / 抗菌 / 数码印花等功能性助剂赛道。
- 对优质客户提供 60–90 天账期换长期框架。
- 跟随产业转移布局肇庆（四会）/ 汕头潮南 / 普宁。
- 建立 REACH-SVHC / OEKO-TEX 合规体系应对出口壁垒。
