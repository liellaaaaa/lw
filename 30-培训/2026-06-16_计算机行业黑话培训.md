# 计算机行业黑话培训

**日期**：2026-06-16（材料正文标注 2026/06/06） ｜ **培训人**：肖聪（AI技术专员） ｜ **学员**：部门内部非技术同事（运营 / 行政等） ｜ **时长**：约 15 分钟
**来源**：桌面导出《团队与培训/260616计算机黑话》（计算机行业黑话培训.md + deck-new 幻灯片）

## 一、培训目标
让非技术同事听懂日常会听到但不懂的技术 / AI 黑话——"听到词能反应过来是啥，饭桌上能装得很懂"。

## 二、核心知识（可直接当速查表用）

### 1. 营销技术黑话（一句话记法：流量=人流，转化=掏钱）
| 词 | 大白话 |
|---|---|
| 流量 | 多少人来访问你的页面 |
| UV | 多少个**不同**的人来过 |
| PV | 页面被浏览多少次（同一人看10次算10次） |
| 转化率 | 来的人里**真完成目标**（注册/购买/点击）的比例 |
| 埋点 | 在页面里偷偷记用户行为，做成数据看板 |
| SEO | 让网站在百度/Google 搜结果里排更前 |
| 爬虫 | 自动去网上抄/抓信息的程序（如批量抓竞品价） |
| 域名/备案/HTTPS | 网站名字 / 国内上线要登记 / 带安全锁更安全的网站 |

### 2. 最易搞混的名字
- **minimax ≠ Mac mini**：minimax 是中国 AI 公司（海螺 AI）；Mac mini 是苹果小电脑，和 AI 无关。
- **ChatGPT / ChatGLM / ChatGPT-4o**：ChatGPT=美国 OpenAI；ChatGLM=智谱清言（国产）；4o/4-turbo/o1/o3 是同一家族不同版本，**GPT 是架构不是"几代"**。
- **Copilot 三兄弟**：微软 Copilot（写文档）、GitHub Copilot（写代码）、比亚迪车机 Copilot（开车）——都叫 Copilot，干的事完全不同。
- **大模型 vs 小模型**：大模型=啥都会点的通才；小模型=某领域更准更快的专才。

### 3. AI / 大模型 / 智能体（最易混三兄弟）
| 概念 | 理解 | 类比 |
|---|---|---|
| AI | 人工智能统称 | "上过大学的大脑" |
| 大模型(LLM) | 靠读海量文字学来的具体技术 | "会读会写的大脑本脑" |
| 智能体(Agent) | 大模型+手脚，能规划、调工具、连续干活 | "大脑配了手和脚" |

智能体相关：MCP=让 Agent 调外部工具的"通用插座"标准；RAG=给 AI 一本开卷考参考书现查现答；WorkFlow=做事的手册/流程图；调用=找工具帮忙；触发=满足条件自动执行。

### 4. AI 工具大家族（按"性格"分，就知道它能干啥）
- 聊天型（你问它答）：ChatGPT、Claude、文心一言、通义千问、Kimi、豆包、DeepSeek
- 干活型/智能体（拆任务、调工具、连续执行）：Manus、Devin、Coze、Dify
- 编程型（陪你写代码）：Cursor、Claude Code、Trae、通义灵码
- 画图 / 视频 / 搜索 / 声音数字人：Midjourney、Sora/可灵、Perplexity、ElevenLabs

> 关键：知道工具属于哪类，就知道它能干不能干。让 ChatGPT"自动订机票"它做不了；让 Manus 它能真去点。

### 5. "听起来吓人但其实不难"的词
| 词 | 大白话 |
|---|---|
| Token | AI 眼里的"半个字"，中文1字≈1–2 token，按量计费 |
| 微调(Fine-tuning) | 拿公司数据再"培训"一遍 AI，让它更懂你业务 |
| 蒸馏(Distillation) | 让"大学生大模型"教"中学生小模型"，跑更快成本更低 |
| Embedding | 把一句话变成一串数字，方便 AI 找"意思相近"的句子 |
| 对齐(Alignment) | 让 AI 别乱说话、别做危险事 |
| 多模态 | 不止看文字，还能看图/听声/看视频 |
| Prompt | 你跟 AI 说的那段话；提示词工程=把话说得 AI 听得懂 |
| 上下文(Context) | 这次对话 AI"还记得"的事，关窗就没了，越长越费 token |
| 温度(Temperature) | 低温(0.1)保守死板、高温(1.0)放飞creative |
| 大模型幻觉(Hallucination) | AI 一本正经胡说八道 → **重要信息要核实** |

### 6. 硬件配置（体检报告：前面数=内存，后面数=硬盘）
- **16+256**：16G 内存（运行内存/RAM，桌面大小）+ 256G 硬盘（存储/ROM，仓库大小）。
- **CPU=左脑**（逻辑，核心少但聪明，普通办公靠它）；**GPU=右脑**（并行，核心极多，画图/AI计算靠它）；**显存(VRAM)=GPU 专属办公桌**（如 4090 的 24G，桌子越大能铺的画布越大，跑大模型/4K视频靠它）。显存≠内存，各用各的。

## 三、防忽悠 3 条
1. 听到"颠覆 / 革命 / 取代人类"先停三秒——90% 是营销。
2. "AGI 马上来了"业内分歧极大，别急着信也别急着喷。
3. **自己上手用 5 分钟，比听 50 分钟 PPT 有用。**

## 四、精华 Q&A
- "调一下 API"= 用一下某个服务的接口，像按自动售货机按钮。
- "Agent 和 AI 啥区别"= AI 是能力，Agent 是用能力去**干活的实体**。
- "RAG 是啥"= 给 AI 一本开卷考参考书，比闭卷猜靠谱。
- "48G 显卡"= 这张显卡的专属办公桌有 48GB 大。
