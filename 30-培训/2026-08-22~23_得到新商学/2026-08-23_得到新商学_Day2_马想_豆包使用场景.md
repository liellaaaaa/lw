# 马想（得到新商学）· 把一个人的内容工厂"复制"出来：skill 是组织的共同语言

**日期**：2026-08-23（周日）
**培训人**：马想（得到新商学，短视频访谈 IP，一年邀请 300 嘉宾被拒 250；用 AI 把内容生产全流程工程化）
**会议**：得到新商学·第 34 场硬件出海 + AI 增长大会·Day2
**来源**：Day2 现场逐字转写整理（lw 在场实录）
**适用读者**：内容 / 运营负责人、想把自己或销冠的"经验"萃取成组织资产的人
**配套**：跨嘉宾横向 → [[2026-08-23_得到新商学_Day2硬件出海与AI增长大会]]

## 一、一句话核心方法论

**「飞书是你的'上下文系统'（知识库 + 协作），豆包企业版是能读电脑 / 文件的桌面智能体；把最有权力 / 最有经验的人（老板、销冠）的工作流写成 skill，装进飞书群，让真人和机器人一起协作——组织的'共同语言'不靠开会传达，而靠共享 skill 自我进化」**。

四件事的排列：① 个人版 vs 企业版四区别 → ② 一套内容生产 skill 链（筛选 / 采访 / 滑稿 / 校稿 / 改写）→ ③ 选题百宝箱 robot 自我进化 → ④ 唐木内容工坊复制（读自己知识库搭系统）。以下逐条展开。

## 二、为什么飞书 + 豆包：个人版 vs 企业版四区别

马想是飞书的死忠："我别的都能换，但飞书从来不换——它就是我的上下文系统、我的知识库、团队内部协作软件。"

他提出个人用 AI 和企业用 AI 的**四个本质区别**：

| # | 区别 | 个人版问题 | 企业版解法 |
|---|---|---|---|
| 1 | **上下文系统** | 个人 AI 每次都是新的，不懂公司 | 飞书沉淀会议 / 文档 / 价值观 / CRM，AI 读得到 |
| 2 | **结果可追溯** | 报告不知怎么来的，只能源于提示词严谨度 | 基于开过的会 / 价值观 / 用户洞察，可溯源 |
| 3 | **规则同版本可调** | 各自用各自 AI，服务客户参差不齐 | 改企业 workflow 里一条 skill，全员同步 |
| 4 | **团队可复用** | 人走电脑拷走 / 删掉，经验流失 | 技能在组织里，人来人走都在 |

> 马想原话："个人用和团队用的区别，就是规则是同样的版本可以调整。所有人都用 AI 工具，和企业用 AI 工具是两件事。不是所有人用 AI，企业就自动用上了 AI。"

> 桌面智能体（豆包企业版）能读电脑 / 文件 / 云端文档，甚至开权限；企业系统工具（飞书 / 钉钉 / 企微 / CRM）是另一摊。目标是让两者交集越来越大。马想坚定试豆包企业版，因为"我们所有工作都在飞书"。

## 三、一套内容生产 skill 链（马想的实战演示）

马想把"访谈节目"全流程拆成多个 skill，演示了完整链路：

### 1. BD+b skill：筛选嘉宾
- 一年邀约 300 嘉宾被拒 250，摸索出成功 / 失败经验写成 skill（正反案例、项目背景、目标、核心工作流、逐步核实标准、标准化输出）
- 指令："帮我找 20 家在深圳做硬件 / 有意思 AI 产品的公司，不要大公司不要融资的"
- skill 做一二三级筛选，带原始链接（防 AI 概率犯错，方便考证），排除原因也写清
- 结果建到飞书多维表格：优先级 / 联创创始人 / 核心产品 / 跑通 0-1 证据 / 团队融资 / 注意事项 / 邀约状态

### 2. 采访 skill：九大问题清单
- 输出格式固定为"九大问题清单"，身份设定："熟练采访 AI 创业者的记者，默认模仿马想采访习惯，大白话、现场感，先给判断关系再问问题"
- 职责：① 获取联系人过去输出内容 ② 分析被访者行业与竞品 ③ 替他洞察市场消费者前景 ④ 模仿马想习惯 ⑤ 问使命愿景价值观 ⑥ 避免被当枪使（成公关口径）⑦ 反问等
- 关键：skill 里写"先搜他在别处输出"，所以 AI 第一个问题就能"假装研究很久"——其实 AI 替你干的

### 3. 滑稿 skill：剪辑师的工作流
- "滑稿"= 给剪辑师标哪些剪掉 / 保留 / 前置 / 突出
- 两小时访谈约 4 万字，AI 自动提取：嘉宾 / 主持人 / 地点 / 核心故事线 / 删减原则（全删 / 压缩 / 保留 / 脱敏）
- 自动提取"开场蒙太奇"（20 秒概括这人是干啥的）、正片剪法、主要删减清单（寒暄喝咖啡聊天气全删、吐槽同行标出）、带数据处提醒对外核实

### 4. 校稿 skill：检查错别字
- 装检查错别字 skill，标出"夏新阳到底哪个新洋""1 easy 哪个词"，确认后二次确认成稿
- 飞书协作：在文档评论里说"把这段删掉"，AI 按批注改——变成协作工作

### 5. 小红书改写 skill：借鉴 → 变成自己的
- 网上找好看的（归藏开源的卡片大师 skill），装上来
- **关键动作："借鉴的 skill 终究要变成我们自己的"**——马想只改一小点："图片右下角默认带猫头鹰"，变成自己 logo
- 结果：每篇统一模板、带自己 logo，且同事也能用

> 马想金句："好看不好看，模型自己抽卡抽不出来，但 skill 一装，统一模板就出来了。而且这个 skill 我和同事都能用。"

## 四、选题百宝箱 robot：skill 在群里自我进化

马想把"给短视频起标题"的 skill 装进飞书群，变成机器人"选题百宝箱"：

- 同事 @ 它："根据这个访谈文档帮我判断标题可不可以" → 它回复并标注"**判断 170**的核心结论"
- "170"代表关于短视频标题这件事，skill 里已沉淀 **170 个判断**，且逐步涨上来（155 → 182 → 183…）
- **每天晚上机器人自己给自己复盘**，讨论出新东西就长出新判断
- 人与 AI 与同事互相协作：同事提"跳出率涨了因为开头讲的不对" + 数据分析 → 马想回复"内容调整优先级：节目列成底线 > 过程指标" → AI 捕捉这句话改造了判断

> 本质：组织的"共同语言、共同规则"不靠开会传达，靠共享 skill 在群里自我进化。谁都能提意见、把外部学的课带回来让机器人学。

## 五、唐木内容工坊复制：读自己的知识库搭系统

马想演示"复制唐木内容工坊"——传一张图（系统截图），问"我想复制这个系统，知识库和历史记录支持吗？"

- 豆包回："你的知识库很丰富，完全支持"——因为日常开会、外部学习笔记、知识库全沉淀到一起
- 第一版五大功能模块：每周选题 / 老板语料库 / 公司资料库 / 本周行业热点 / 封面素材库
- 关键发现：**提示词里没给任何输入（没说马想是干啥的），但 AI 给出的选题精准**——因为知识库里有"一次花一天半听的短视频课，给短视频分了 11 类"，AI 自动用到工作台
- 还能读第三方付费抓取工具（如"梅训助手"抓抖音 / 小红书 / Facebook），自动入库、高热度标红、给详细解读 + 可用角度
- 闭环：授权豆包用浏览器打开抖音后台扫码登录 → 每天 5 点自动抓取进多维表格

> 马想强调："这个工作台第一天问世，好多功能没点。重点是——你的料足够多，它只是原来没以这种形式整理下来。"

## 六、得到大脑 CLI 双向奔赴：自动化打通多系统

马想的最后一个场景："无论用任何桌面智能体，记得打开飞书文档和得到大脑的双向奔赴。"

- 自动化任务：每天晚上 10 点，飞书和得到大脑互相检查"你有我没有"，彼此分享
- 飞书开发者平台的飞书 CLI / 豆包企业版默认能读飞书；得到大脑官网也有此功能
- 不会自动化？先多次对话，最后补一句"把这个改成自动化"

> 更深的场景：让豆包读最近一个月飞书文档 + 群聊里"怎样回复用户的问题"，萃取成 skill 封装成智能体给同事用——把"最有权力的人（老板 / 销冠）"的经验变成组织共有资产。

## 七、可复用提示词 / 话术

1. **"飞书是我的上下文系统"** —— 知识库 + 协作的定位宣言
2. **"个人用 AI 和企业用 AI 是两件事"** —— 四区别的总纲
3. **"借鉴的 skill 终究要变成我们自己的"** —— 复用改写的铁律（改右下角猫头鹰）
4. **"所有给的新闻信息都要带原始链接，方便回头考证"** —— 防 AI 概率犯错的 skill 写法
5. **"组织的共同语言不靠开会，靠共享 skill 自我进化"** —— 选题百宝箱 robot 的本质
6. **"你的料足够多，它只是原来没以这种形式整理下来"** —— 唐木工坊复制的前提：先沉淀

## 八、避坑清单（马想版）

| # | 坑 | 真实后果 |
|---|---|---|
| 1 | 以为装了 AI 工具 = 企业用上了 AI | 各自为政，服务参差不齐 |
| 2 | 个人 AI 每次从头来，不接上下文 | 结果不可追溯、不可复用 |
| 3 | 照抄别人 skill 不改成自己的 | 模板统一但带别人 logo，不是资产 |
| 4 | 让 AI 出新闻不要求带链接 | 概率犯错无法考证 |
| 5 | 组织的规则靠开会传达 | 层层损耗，科室不共享 |
| 6 | 最有经验的人（老板 / 销冠）经验不萃取 | 人走经验走，新人从零来 |
| 7 | 材料只在单一工具里，不进协作群 | 真人机器人无法一起干活 |

## 九、lw 联想（外贸 / 采购 / AI 项目方法论）

### A. 与外贸业务线相关的 3 件可做之事

1. **"外贸销冠分身"萃取**：照马想"萃取最有权力的人"思路，把公司外贸骨干的历史跟进 / 开发信 / 谈判话术写成 skill，装进船务 / 外贸群，新人 @ 它拿建议——对应金柯"销售老大分身"。
2. **客户沟通校稿 skill**：把马想"校稿 / 滑稿"思路用于外贸——每次发给客户的开发信 / 报价话术，AI 先按品牌调性校一遍（脱敏 / 术语 / 语气），再发出。
3. **选题百宝箱式自我进化**：外贸素材库可做成一个 robot，每次新客户 / 新市场反馈都长出新"判断"，越用越懂宏昊的外贸语境。

### B. 与采购分析业务线相关的 2 件可做之事

1. **采购"供应商回复助手"萃取**：把采购骨干"怎么跟供应商砍价 / 怎么判断履约风险"的经验写成 skill 装群，新人遇到拿不准的供应商直接 @。
2. **采购知识库双向奔赴**：照"得到大脑 CLI 双向奔赴"，把 ProcurementAnalysis 的数据和飞书 / 企微文档每天互相同步，避免"料散落"。

### C. 与 AI 项目方法论相关的 3 件可做之事

1. **宏昊AI助手定位 = 马想的"上下文系统 + 桌面智能体"**：马想的飞书 + 豆包组合，正是宏昊AI助手"文档管理中心（上下文）+ 智能体（桌面智能体）"的范式——可直接拿来对内讲清楚架构。
2. **skill 模板库 + 改成自己的**：马想"借鉴归藏改猫头鹰"的做法，应成为公司 skill 开发规范：先用市场 skill 学框架，必须改成带宏昊 logo / 业务口径的版本才算交付。
3. **最有权力的人萃取**：目前宏昊AI助手的知识来自研发上传，但"怎么用"的经验在业务骨干（肖聪 / 外贸 / 采购）脑子里。应启动"把骨干经验写成 skill 装群"的动作——这是金柯 FE + 马想萃取的共同落点。
