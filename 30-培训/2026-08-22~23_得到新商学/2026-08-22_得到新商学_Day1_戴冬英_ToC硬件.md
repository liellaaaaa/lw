## 一、一句话核心方法论

**「从渠道爆品到全域爆品的距离 = 产品力 + 内容表现力 + 运营力 + 客服承接力，这四件事扎根到底；AI 落地的关键是'重塑岗位价值'，而不是'降本'或'加工具'。」**

Helen 9 年创业，把 3600 万的"渠道爆品"做成了 5000 万的"全域爆品"——单品。同时踩过 1500 万的抖音自营亏损。

## 二、四能力扎根：从渠道爆品到全域爆品

Helen："**不是只多开几家店、多投一些流量**。需要企业具备："

| 能力 | 含义 | 关键动作 |
|---|---|---|
| **产品力** | 产品本身能打（开品 / 设计 / CMF / 极致性价比）| 渠道需求洞察 → 抢空白 → 快速验证 |
| **内容表现力** | 把产品讲明白，让用户一眼看出价值 | 按人群拆解素材（不按"故事线路"）|
| **运营力** | 多渠道协同，把爆品放大 | 传统电商→用户沉淀 / 内容电商→品效合一 / 达人→爆品放大 / 大客户→营收能量 |
| **客服承接力** | 客户来了接得住（咨询 / 售后 / 复购）| 团队模块化、AI 辅助回复（白天 + 夜间）|

> "渠道爆品不等于增长能力——它只是在现有流量平台和成熟机制下成交。真正全爆品要扎根经营能力。"

## 三、打深不打宽：年十几个品 → 单品 5000 万

### 3.1 现状反思

Helen 的反思："每年做十几个品、销售额过亿，但利润没涨——其实在赚辛苦钱。"

| 旧模式 | 新模式 |
|---|---|
| 年开十几个品 | 锁定人体工学赛道 |
| 抢渠道空白、铺得多 | 锁定目标用户、最小 MVP、系列展开 |
| 模具一套套开 / 人员上涨 | 同样销售额只做一个品 → 边际成本下降 |

**第一性转变**："宽 1 米 vs 深 1 万米"——Helen 决策"转型缩小井口、挖深"。

> 扁平化设计是乐范的强项（拿过全球设计大奖），加上深耕健康行业 20 年——这两个"先有"的禀赋是"打深"的底气，不是每个公司都适用。

### 3.2 魔力贴案例（老业务回顾）

- 2017 年 7 月 13 日上线"口袋里的按摩师"
- 第一天 4000+ 个售罄
- 三个月（7 月底到年底）销售 3600 万
- **第二年做到小米平台健康类目 KA 过亿**
- 年年稳定产出"过亿大单品"

> 关键产能能力 = 平台洞人员察 + 设计 / CMF / 工艺研究 + 极致性价比。这套"开品能力"是 1.0 阶段的核心。

## 四、抖音自营踩的坑：1500 万亏损的三个转变

Helen 这次演讲的最大"反向教材"——**创业路上的真实亏损**。

### 4.1 亏损路径

| 动作 | 后果 |
|---|---|
| 自建 30 人团队 | 一个月组建完，编导 / 拍摄 / 剪辑 三五成组 |
| 代运营 / 操盘手套路 | "再等一等账号起点"——投了单 ROI 跑正 |
| 极致投流 | 单品短期量很大，整体 ROI 不正 |
| 一年后砍掉团队 | 30 人解散，亏损 1500 万 |

### 4.2 三个核心转变

> Helen："最大的三个转变——**第一，数据不能只看结果。第二，项目一定要止损。第三，单一传统模式一定不能带来持续增长。**"

| 转变 | 旧 | 新 |
|---|---|---|
| 数据 | 只看 GMV / 销量 | 必须看过程：架构 / 支付 / 转化 / 退货 / 复购 |
| 止损 | 操盘手说"再等等"就再等等 | 明知模式不对还硬撑 = 真失败 |
| 增长 | 单一传统模式（投流 + 短视频）| 多模式协同（电商 + 内容电商 + 达人 + 大客户）|

> "你永远赚不到认知以外的钱。出去学习不是什么都自己做，是要知道**看什么 + 怎么算**。"

## 五、内容侧变革：从按故事拍 → 按人群拍

### 5.1 旧模式（按故事线路）

- 一条创意讲完产品的所有功能
- 偏概念 / 偏品牌叙事

### 5.2 新模式（按人群拆解）

Helen 用"沙发产品"举例，**按人群分别做内容**：

| 人群 | 痛点 | 卖点切角 |
|---|---|---|
| 小孩 | 不损脊柱、健康成长 | 健康材质 / 结构安全 |
| 上班族 | 回到家舒缓后背 | 三段式支撑 / 内嵌 80° |
| 老人 | 起身容易 | 轻便（不到一个西瓜）/ 承重 220kg |

每条素材拆成 3–5 秒开头 + 痛点 + 产品 + 卖点 + 转化，**最终素材库是一个沙发有正面 / 侧面 / 底面 / 不同人群使用**。

> "**一具体就深刻**——具体到人群、具体到场景、具体到动作，片子出来的感觉完全不一样，爆款会越来越多。"

## 六、数据侧变革：一张仪表盘看所有

Helen 用 **飞书 + 多维表格 + AI** 把所有店铺数据放在一张表盘：

| 仪表盘功能 | 实际意义 |
|---|---|
| 数据自动更新 | 一键刷新 |
| 过程指标突出 | 直接看到每个店铺的入口量 / 加购率 / 询盘 / 转化 / 退货 |
| 多渠道一张表盘 | 抖音 / 天猫 / 京东 / 小红书 全部横向对比 |
| 周期可选择 | 周 / 月 / 季度 / 年 任意切 |

> **核心价值**：以前一个店铺要"店长 + 推广 + 数据助理"3 人，现在仪表盘自动对齐 + 复盘。"一旦对齐，立刻很多问题就能看到。"

## 七、渠道协同矩阵：4 个渠道 4 个作用

Helen 现场画的矩阵，**最值得借鉴**：

| 渠道类型 | 作用 | 关键动作 |
|---|---|---|
| **传统电商**（天猫 / 京东） | **用户积累 + 沉淀** | 关键词 + 人群 + 内容组合，把爆品在站内放大 |
| **内容电商**（抖音 / 小红书） | **品效合一 + 营销** | 内容创作 + 品牌叙事 |
| **第一达人合作** | **爆品放大** | 母婴测跑爆 → 促天猫用关键词 / 人群 / 内容接住 |
| **大客户合作** | **营收能量** | B 端 5 折营销 + 高端渠道推荐 |

> 经典案例：花姐直播间，沙发 10 分钟销售 50 万，得到直播间连续 3 天破 100 万，单品年销 5000 万。**关键**：达人侧爆了 → 站外（小红书短视频 + 3D 卡直播）种草 → 站内（天猫）关键词 / 人群 / 内容接住 → 大客户做"5 折营销"放大声量。

## 八、AI 落地三步：从最小闭环 → 中台能力外溢

### 8.1 第一步：找到"高重复的最小闭环"（速胜战）

Helen 的 AI 第一个落地场景：**设计出图**。

| 环节 | 旧模式 | 新模式（用 AI 后）|
|---|---|---|
| 一张主图打磨 | 7–10 天 | 1 天 |
| 设计师要求 | 专业设计 + 美工 | 普通员工也能用 |
| 业务对接 | 运营 → 设计 → 反复轮回 | 业务直接出图 |

**关键**：先把"好员工的经验"萃取出来做成"提二 / 蒂二"——输入什么产品 + 什么颜色 + 什么人 = 一张图。"把能力很强员工的经验萃取出来形成固化知识，其他不懂的员工直接调用就 OK 了。"

### 8.2 第二步：横向扩到中台其他岗位

- 美工从"按需出图" → "产品研发（参数具象化、3D 化）"
- 美工的考核从"按时完成率" → "产品开发数 + 准确性"
- 美工从"成本岗位" → "创收岗位"（接外单 / 做副业）

### 8.3 第三步：把中台能力产品化（外溢创收）

> "中台不应只是费用部门，而应贡献利润佣金。"

- 美工设计的"沙发背景图"在抗美援朝展上被 5000 个嘉宾用——AI 生成的沙发布景
- 帮某知名茶叶平台、高铁候车室推车、三面产品、品牌全案——限制性承接
- 中台从"内部费用" → "外部创收"——这才是"AI 让中台不等同于成本"的关键

> "以前根本不敢接非公司主线的全案项目。但接了好多个——其实是限制性承接，因为要有自己的主线任务。这只是副业。"

### 8.4 AI 在岗位上的真实改变

| 岗位       | AI 之前的痛      | AI 之后的变化       |
| -------- | ------------ | -------------- |
| 店长       | 推广 + 美工两件事拉胯 | 一个人兼顾三人工作      |
| 运营       | 找素材 + 出图     | AI 直接生图 + 优化   |
| 设计       | 按单做图         | 出图 + 副业 + 研发   |
| 客服       | 一个人接 N 个咨询   | 效率提升 3–5 倍     |
| 开发       | 抄代码          | "管理 10 个应届生"一样 |
| 物流 / 供应链 | 对账慢          | 对账效率提升 50%     |

## 九、AI 时代的关键认知

### 9.1 "AI 不能替代岗位，而是用 AI 的人替代很多人"

- 老板一定要自己用 AI，否则"会很割裂"
- 找到"业务高度依赖、重复经验的最小闭环"
- 跑出来就是标杆案例——在公司里就会有现身说法

### 9.2 "把工作看成能力组合，不看成岗位分工"

> "AI 时代要改变的不是给每个岗位加工具，而是把工作看成能力组合。**人负责决策判断，AI 执行大量重复工作。**"

具体含义：
- 岗位不能再按传统分工
- 员工应该拓展能力边界（店长不只是店长，可以是内容 / 美工 / 数据）
- 公司应让员工发挥价值并提供滋养土壤

### 9.3 AI 落地的"落地三原则"

1. **从最小化单元跑起**（不要一上来铺开）
2. **不停留在"加工具"，要重塑岗位价值**（不是降本，是创造）
3. **可以创造新价值**（中台接外单反哺利润）

## 十、可复用提示词 / 话术

下面 8 条是 Helen 反复强调的金句：

1. **"不是 AI 替代岗位，而是用 AI 的人替代很多人"** —— AI 是杠杆
2. **"不亲自用 AI 就会很割裂"** —— 老板必须下场
3. **"中台不应只当费用部门，要贡献利润佣金"** —— 中台能力产品化
4. **"你永远赚不到认知以外的钱"** —— 出去学习要会算账、看过程
5. **"具体就深刻"** —— 抓核心、做具体、不要大而全
6. **"互联网是放大器，不是转化器"**（与李文录 / 唐沐共鸣）
7. **"止损不是失败——明知模式不对还不止损，那才叫失败"**
8. **"AI 不能替代人，但要让人做得更好"** —— 人做决策和审美，AI 做重复

## 十二、lw 联想（AI 项目落地 / 培训推广 / 内容创作）

### A. 与退税审单 / 工具型 AI 相关的 3 件可做之事

1. **"过程指标"对照**：OCR + 规则引擎型工具不能只看"通过率"，要分阶段拆漏斗（识别 / 抽取 / 校验 / 通过）——和 Helen 的"架构 / 支付 / 转化 / 退货 / 复购"思路一致
2. **"找最小闭环跑通"**：退税审单可以先跑"单字段识别准确率"再扩展"全文档一致性"
3. **"中台能力外溢"**：宏昊AI助手的中台（文档解析 / 知识召回 / 工作流编排）以后可以做成可对外的子产品——目前没设计这条路

### B. 与培训推广相关的 3 件可做之事

1. **"按人群拆内容"**：培训内容不应按"功能模块"组织（AI 助手怎么用），应按"岗位角色"组织（财务 / 销售 / 采购 / 人事分别怎么用）——目前培训助手按课程分类，可考虑双轨
2. **"具体才深刻"作为口号**：比"AI 赋能"实在得多——以后做培训宣传可用这个
3. **"标杆案例 + 现身说法"**：先找 2–3 个标杆用户，跑通后请他们做内部分享

### C. 与个人认知 / 学习成长相关的 2 件可做之事

1. **"你想清楚 AI 在公司中的作用——思考 AI 解决什么问题，而不是盲目学习"** —— Helen 在公司内部天天说的这句，可以作为 lw 个人判断 AI 工具价值的标尺
2. **"找到高度依赖、重复经验的最小闭环"** —— 不只是企业，个人成长也找最小闭环（先把一件事跑通，再扩）
