# 李文录（必一能源源）· ToB 外贸怎么做 98% 大客户转化率

**日期**：2026-08-22（周六）13:00–19:00
**培训人**：李文录（必一能源源创始人，在外贸圈被称"李广库"）
**会议**：得到新商学·第 34 场硬件出海 + AI 增长大会·Day1
**来源**：Day1 现场逐字转写整理（lw 在场实录）
**适用读者**：ToB 外贸、ToB 销售、跨境业务负责人
**配套**：跨嘉宾横向 → [[2026-08-22_得到新商学_Day1硬件出海与AI增长大会]]

## 一、一句话核心方法论

**「不是先有营销，而是先懂行业；不是卖产品，而是关心客户的生意——把'销售关键行为'拆细、挂到时间节点上，让组织像流水线一样自己跑」**。

四件事的排列组合：① 选品先懂产业（不是先做流量）→ ② 区分 B 与 C（不是高中低）→ ③ 流程标准化（不是靠个人英雄）→ ④ 关心客户生意（让客户变大自己变大）。以下逐条展开。

## 二、选品的四步法（不是流量先行）

李文录说："中国不缺品。打开 1688，每个品都有几千个供应商在卖。所有人都开始做流量，先做营销再找品，活不过 6 个月。" 真正的选品四步：

| 步骤 | 动作 | 关键产出 |
|---|---|---|
| 1 | **看数据**：阿里国际站数据参谋、Google Trends 交叉验证 | 找到"看着热"的赛道 |
| 2 | **走进产业带**：走访头部供应商、工厂，了解真实供需 | 区分"真热"还是"被头部吃剩" |
| 3 | **B 端 / C 端痛点匹配**：看 Amazon 评论、跨境 B 端买家抱怨 | 找到"双方都想要的解决方案" |
| 4 | **竞争空间评估**：能否解决被头部放弃的痛点 | 判断能不能进 |

> 数据例：李文录用"高尔夫球车"举例，阿里站内热度排第 7，Google Trends 从 2021 起稳定 → 走进产业链 → 发现 60% 成本集中在三大件（电机 / 电控 / 电池）→ B 端客户抱怨"无法解决海外售后" → C 端 Amazon 评论同样抱怨 → 痛点完美匹配 → 进入。

**核心心法**：B 端与 C 端痛点能匹配上的赛道，哪怕你只做"贸易"，也能吃下来。

## 三、客户分层：只有 B 和 C

李文录："在外贸没有高中低，在外贸只有两种客户，一个叫 B，一个叫 C。要想做产品，你一定要这样做，你就要做 B 还是做 C。"

| 维度 | B 端客户 | C 端客户 |
|---|---|---|
| 流量成本 | 高（L3+ 才能匹配）| 低 |
| 成交速度 | 看专业度，可一天成交 | 快 |
| 客单价 | 高 | 低 |
| 复购率 | 高（信任建立后）| 低 |
| **隐性成本** | **低**（无退货、无 7 天无理由）| **高**（售后 + 退货吃掉毛利）|

> "真正赔钱的生意都在 C 端。看似成交快、流量大，最终都在赔钱——那些成交量是表象。"

**lw 启发**：这条规则可以迁移到供应商分级——能稳定批量供货的（B）、小作坊式一次性供货的（C），库存策略和合作深度要差异化对待。

## 四、外贸成交五阶段（陌生人 → 熟人 → 成交）

李文录反复强调的"陌生人做生意"五步：

| 阶段 | 目标 | 关键动作 |
|---|---|---|
| 1. 破冰 | 从陌生人到认识 | 不用"请问您要什么数量"，用"你是做什么的 / 你从哪个渠道知道我们"建立连接 |
| 2. 画像 | 知道客户是谁 | 用 Google / Facebook / LinkedIn 把客户公司架构、行业、上下游挖清楚 |
| 3. 方案 | 知道客户要解决什么问题 | 不卖产品，给客户做"商业计划书"（现状 + 解决方案 + 经济效益）|
| 4. 信任 | 让客户相信你能解决 | 用"你比他更懂他的生意"建立专业信任 |
| 5. 成交 | 单子落地 | 把价格 + 物流 + 售后条款敲死 |

> 真实案例（2025-03-14 晚 11 点的询盘）：客户说"我对你的产品感兴趣，想买一台"——表面是 1 台样品，实际通过画像挖出是法国物流园，做油改电业务，需求是 100 台 + 区域代理。最终一单从 1 台变成 100 台 × 7 万 = 700 万，再到区域代理 500 台 × 7 万 = 3500 万。

**lw 启发**：这个五阶段是销售流程标准化的核心。可以直接对接 AI skill 改造——AI 帮客户做画像 + 商业计划书，把销售前四个阶段砍掉一半人力。

## 五、自运转销售流程（24 / 48 / 72 小时）

李文录团队把每个客户当成"流水线上的一个工件"，每个节点有固定时间和责任人：

| 节点 | 时间限制 | 责任人 | 没完成动作 |
|---|---|---|---|
| 客户询盘 | 24 小时 | 销售 → 转入下一节点 | 未读 / 已读不回 → 拉黑 |
| 客户触达 | 2 小时内画客户画像 | 销售 → 深度沟通 | 24 小时内必做 |
| 深度沟通 | 48 小时给到方案 + 报价 | 销售 → 报价 → 谈判卡点 | 必进入议价 |
| 报价 | 72 小时必回流（不一定成交）| 销售 | 卡住 → 拉到谈判卡点 |
| 谈判卡点 | 主管帮解决 | 主管 | 主管解决不了 → 拉老板 |
| 合同 | 72 小时内付款 | 销售 → 待成交卡点 | 老板亲自跟 |
| 待成交 | 老板出面 | 老板 | 落袋为安 |

> 这套流程跑出 1680 万美金/年线上订单、98.95% 订单转化率（行业平均 60%）、平均付款时长 4 天 11 小时（行业更高）。

**关键**：所谓"自运转"不是没人管，而是每个阶段都有责任人兜底——卡住有组长、组长卡住有主管、主管卡住有老板。"组织不会自己产生战斗力，必须把方法论写到流程里。"

**lw 启发**：这是 ProcurementAnalysis 缺少的一环。目前采购动作没挂时间节点 + 责任人，应该补一个"采购动作看板"模块。

## 六、管 90 / 00 后：盯关键行为，不盯人在不在

李文录的"老板爹味儿太浓"自我复盘很经典——年轻员工离职原因就是"单位老板爹味儿太浓"。结论：

1. **岗位说明书下面贴一层"量化工作标准"**：每天联系多少客户、每周几次报价、每月几个合同——动作可量化，绩效才有效
2. **不要相信自己的眼睛**：那个下班就走的孩子是因为晚上 9:30 闹钟响起来继续对接南美客户，要用数据看而不是用"看起来"看
3. **管结果不管过程**：只要每天把定量工作完成 / 每月最低销售目标完成，"你爱戴耳机就戴耳机，你爱穿啥就穿啥"

> "工作量最大的不一定是业绩最好的。但工作量最小的一定是业绩最差的。"

## 七、关心客户生意：从卖产品到卖增长

李文录的原话："我每年都给客户做年度分析报告。旺季在哪里 / 哪个月该提前下订单 / 你未来要增长多少 / 我们能怎么帮你。"——把客户当"经营对象"而不是"采购对象"。

两个核心招式：

### 招式 1：让客户变大（用利润空间换取采购量）

- **年度返利**：不降价，只在客户年采购量达 X 时返利 Y%——既保毛利，又给客户规模动力
- **采购群体变大**：建议客户拓店、加 SKU，甚至说"你拓到 300 万，你多出的成本我们承担"——把客户做大，自己才能做大
- **逆向：把 C 推给 B**：70% 流量是 C，但 C 端推给自己 B 端客户做分销——C 流量不浪费

### 招式 2：解决 C 端 / B 端的"售后悖论"

- 用"借力"——找到目标城市所有维修站打电话，给他们 120 美金/单的维修费，自己收客户 150 美金/次——既解决客户售后痛点，又加利润
- "出海有时候不需要我们什么都做。我们只是做自己的专业车行，我就铆定一个专业城市。"

> "客户为什么不增长？客户为什么变不成百万级、千万级的买家？其实最关键的就是他的生意不好。我们不去让他变大，生意就不会好。"

## 八、可复用提示词 / 话术

下面 6 条是李文录当场反复强调的金句，直接可以拿去当培训教材或 prompt：

1. **"永远不要相信客户第一次提出来的需求"** —— 客户说"想买一台"通常只是试探，必须挖真实诉求
2. **"我明明就想买一个产品，但是我从来没有见过一个中国供应商比我还关心我的生意"** —— 这是从 1 台到 3500 万生意的关键转折
3. **"破亿跟你的产品单价没关系，跟你的客户结构有关系"** —— 单价低不是借口，关键看你怎么结构化客户
4. **"不要跟他聊产品，要关心他的生意"** —— 销售要做的是补上客户差的那一块
5. **"互联网是放大器，不是转化器"** —— 流量大不等于成交多
6. **"如果你作为一线销售，你今年银行卡的存款不增长，今年的工作就没有价值"** —— 对客户的增长负责，才对自己负责

## 九、避坑清单（李文录版）

| # | 坑 | 真实损失 |
|---|---|---|
| 1 | 先做流量再找品 | 6 个月内信息断流，店铺死亡 |
| 2 | 把客群分高中低端 | 起步阶段没资格分客户 |
| 3 | 用推品代替关心客户生意 | 复购死、利润缩 |
| 4 | 老板年度才出现一次 | 砸桌子摔杯子也救不了指标 |
| 5 | 盯人盯出勤管理年轻人 | 招不到人，留不住人 |
| 6 | KPI 只讲结果不讲过程 | 操盘手套路你（"再等等"）|
| 7 | "未来有报价机器人"就让销售停摆 | AI 是补充不是替代；要做"关心客户生意"的人 |
| 8 | 拒接售后问题（"供应链都解决不了"）| 错过最大痛点；纯贸易也能靠借力破局 |

## 十、lw 联想（外贸 / 采购 / AI 项目落地）

### A. 与外贸业务线相关的 3 件可做之事

1. **外贸开发信 skill 改造**：把"五阶段（破冰→画像→方案→信任→成交）"喂给 AI，让外贸智能体能跑完前四个阶段，把单业务员前 3 天的工作量压到 1 小时
2. **客户画像自动化**：把 Google / Facebook / LinkedIn 调研步骤固化进 skill，1 分钟出客户全貌（而不是手动挖 2 小时）
3. **大客户年度复盘模板**：照搬李文录的"客户年度分析报告"，给船务助手 / 外贸助手的 VIP 客户做

### B. 与采购分析业务线相关的 2 件可做之事

1. **采购动作看板**：把每天询价次数、跟踪供应商次数、条款评审次数挂看板——李文录的"动作量化"思路可以用到采购 SOP
2. **供应商画像**：照"五阶段"做供应商背景调研（B 端工业供应商 vs C 端小型作坊），给 ProcurementAnalysis 增画像维度

### C. 与 AI 项目方法论相关的 3 件可做之事

1. **"互联网是放大器不是转化器"** 这句话直接写进 AI 工具落地的"先转化后流量"准则
2. **流程标准化 = 把方法论写到 SOP 里**——可以用宏昊AI助手帮销售团队生成行业 SOP，目前没做到"自动 SOP 化"
3. **管理层 vs 90 后的张力解决**：90 后管理用"关键行为"而非"盯人"，对应 AI 工具推广要用"让员工多做什么"而非"替员工做什么"
