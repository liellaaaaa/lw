## 三、跨嘉宾共鸣主题（横向对比）

> 下面 7 条是 Day2 全场反复出现的共识，按"信号强度"排序。每条都至少 2 位嘉宾反复强调过、或在不同语境里指向同一结论。

### 1. 「企业知识库是给 AI 看的，不是给人看的」—— 上下文工程是地基

- **张轩铭**原话："企业知识库不是给人看的，是给 AI 看的。你只需要把业务的经营过程、跟客户沟通的记录放进去。"
- **金柯**：豆包企业版中间是组织知识（所有聊天 / 会议 / 审批 / 业务系统 / 文档全沉淀），AI 才越来越懂企业。
- **潘逸舟**：飞书提供"企业知识和业务数据，为组织间数据传播提供基座"。
- **马想**："飞书就是我的上下文系统"；唐木工坊能搭出来，是因为"你的料足够多"。

**实操含义**：宏昊AI助手"文档管理中心"应明确"主要给 AI 检索"的定位，而不是只做"人查资料"的网盘——这与 Day1 笔记"资料散落根因"治理方向一致。

### 2. 「个人提效 ≠ 企业提效」—— 组织级落地才是真问题

- **金柯**两个血案：① 一人兼三岗离职，老板须招两人顶；② 员工用 AI 做图猛但仍刷短视频，3 小时活 10 分钟干完却等到节点才推。
- **张轩铭**："知识不属于组织"——员工离职带走经验，组织无积累。
- **潘逸舟**："光靠豆包，效果可能是一次性的"——要飞书承载才成流程。
- **马想**：个人用 AI 和企业用 AI 是两件事，四区别（上下文 / 可追溯 / 规则同版本 / 团队可复用）。

**实操含义**：宏昊AI助手当前指标停在"使用次数 / 满意度"（个人视角），缺"过程指标"和"组织沉淀率"——要补到企业视角。

### 3. 「skill / 工作流是 AI 落地的真正单元：重复的事固化成工作手册」

- **张轩铭**："重复做重复的事情，最多做两次，以后都不要自己做了。" skill = 员工工作手册，分四复杂度（助手→专员→专家→团队）。
- **金柯**：FE 写 4 万字提示词 / 场景，把销售老大经验固化成"销售老大分身"。
- **潘逸舟**："skill 不是拿来用，是拿来改的"——先学框架再改。
- **马想**：把筛选 / 采访 / 滑稿 / 校稿 / 改写全写成 skill，且"借鉴的 skill 终究要变成自己的"。

**实操含义**：公司内部已有退税审单 / 采购分析 / 培训助手等 skill，应按"助手→团队"四档盘点，建"改成自己的"规范，避免重复造轮子。

### 4. 「工具会换，但工作的'技能'不会变——沉淀的是技能不是工具」

- **张轩铭**："工具可能两三月一换，但工作的技能 AI 去执行，短期之内一定不会变。"
- **马想**："借鉴的 skill 终究要变成我们自己的"——改右下角猫头鹰才是交付。

**实操含义**：推动 AI 落地别追新工具（Day1 林莹莹也提过"老板追新工具耽误结构"），把"换工具不变技能"作为推广话术。

### 5. 「老板 / 超级个体的认知天花板被突破：AI 做战略部 / 分身 / 秘书」

- **张轩铭**：搭建自己的"AI 战略部"，帮老板做更深入全局的分析。
- **金柯**："销售老大分身" + "AI 小秘书督办"——老板只需想清楚怎么管。
- **马想**：把"最有权力的人（老板 / 销冠）"的经验萃取成 skill，装群让组织共有。

**实操含义**：宏昊AI助手的价值主张应从"替代动作"升级到"突破老板 / 骨干的认知天花板"——这正是 Day1 笔记"AI 重塑岗位价值"的延伸。

### 6. 「可追溯 / 可协作 / 同版本：企业用 AI 和所有人用 AI 是两件事」

- **马想**四区别：上下文 / 可追溯 / 规则同版本可调 / 团队可复用。
- **潘逸舟**：HTML 材料可编辑、可带权限分享、可二次协作——不是一次性。
- **金柯**：改企业 workflow 里一条 skill，全员同步，不用每人重学。

**实操含义**：宏昊AI助手若进企微 / 飞书群，必须支持"同版本规则 + 群协作"，否则又是个人玩具。

### 7. 「从 PPT 材料转向 HTML 材料」—— 今年材料形态共识

- **潘逸舟**："今年非常建议从 PPT 材料转为 HTML 材料"——AI 可读、人舒服、可交互可协作。
- **马想**：自己分享也全改 HTML；"每一次老师讲都切成 HTML"。

**实操含义**：宏昊AI助手 / 培训助手对外输出，应从纯文本 / PPT 转向"可编辑可交互的 HTML 网页"，便于在企微 / 飞书流转。

## 五、lw 的整体收获（与外贸 / 采购 / AI 三条业务线）

把 Day2 的 4 讲沉淀后，可以拉出三条业务线对应的"今天以后可以做的事"：

### A. 外贸业务线

- **外贸"销冠 / 老大分身"**：把金柯"销售老大分身" + 马想"萃取最有权力的人"合并，写成外贸跟进 skill 装群，新人 @ 即拿建议——直接对接 Day1 李文录五阶段。
- **降填写门槛**：学金柯"说一句话 → AI 解析结构化字段 → 确认即沉淀"，把 shippiing_helper 录入从手动变口述。
- **外贸内容流水线**：学潘逸舟"爆款仿拍"式多维表格 + 定时任务，每天抓取行业 top 内容批量生成开发信 / 朋友圈素材。

### B. 采购分析业务线

- **采购"五个黑洞"自检**：ProcurementAnalysis 当前只解决"有系统"，没解决"真用 / 用对 / 增长"，应加量化 + 质检环节。
- **供应商知识问答 Agent**：搬金柯"T 哥"模式，群里问"这供应商历史履约咋样"AI 自动回。
- **采购数据交叉校准**：用潘逸舟"双任务框互校"提升报表准确率。

### C. AI 项目方法论线（宏昊AI助手 / 培训助手 / skill 资产）

- **明确"AI 交付工程师（FE）"角色**：肖聪实际就在干 FE 的活（串业务流程 + AI 能力），应把"提示词 / 业务逻辑梳理"写成正式职责——这是 Day1"岗位能力工程化推动者"的落地。
- **知识库定位纠偏**：文档管理中心明确"给 AI 看 + 组织共有"，呼应 Day1"资料散落根因"治理。
- **skill 资产管理规范**：建"助手→团队"四档盘点 + "改成自己的"交付规范（借鉴市场 skill 必须改宏昊口径 / logo 才算交付）。
- **输出转 HTML**：宏昊AI助手 / 培训助手从纯文本 / PPT 转向可交互 HTML 网页。
- **过程指标补全**：从"使用次数 / 满意度"补到"知识库命中率 / 首次提问解决率 / 组织沉淀率"。
