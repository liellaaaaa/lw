## 三、跨嘉宾共鸣主题（横向对比）

> 下面 6 条是 Day1 全场反复出现的共识，按"信号强度"排序。每条都至少 2 位嘉宾反复强调过、或 2 位嘉宾在不同语境里指向同一结论。

### 1. 「互联网 / AI 是放大器，不是转化器」—— 流量解决"规模"，转化解决"承接"

- **李文录**原话："互联网是一个放大器，它能把你的规模、把你想做的事情无限的给你放大。但是大家记住，互联网是放大器，互联网不是转化器。"
- **戴冬英**抖音 1500 万亏损的根因：操盘手只看前端 ROI，老板没看架构 / 支付 / 转化 / 退货 / 复购这些**过程指标**，结果在前端 ROI 跑正时整体失血。
- **林莹莹** 1.0 阶段死掉也是同一结论：把流量冲到行业前二，但商机转化率只 2.97%，客户看了店铺就走。
- **唐沐** 同样：扫地机器人之所以成，是因为用"用户可接受价格 + 用户可感知价值"——单讲流量和故事已经不够了。

**实操含义**：AI 来了不是要让人换跑道，而是**先有承接（产品/团队/流程），再决定上多大流量**。lw 这边用在：宏昊AI助手 / 培训助手 / 工具型 skill 上线前，必须先把转化动作（bot 注册、首次答得对、使用频次）跑通，再去拉升指标。

### 2. 「创始人必须自己下场，且一定要会看过程指标」—— 老板不是旁观者

- **戴冬英**："老板一定要用 AI。若自己不用只让底下人用，会很割裂。"
- **李文录**："我不是转化率不行吗？当时我觉得转化能力是最头疼的。所以我把这两年的数据全部拉出来..."——老板要亲自盯看板。
- **唐沐**："作为创始人，我是要去看店，否则我拿不到场品的第一手消息。永远不要相信你的人出去，到完店之后回来给你汇报。"
- **林莹莹**："我们老板侧的经营管理... 千万不能听他用意，不要想着什么都做好。"——抓核心 KPI（大客户）而不是展开太多维度。

**实操含义**：AI 项目的"过程指标"目前在哪？我对宏昊AI助手的指标拆解还停在"使用次数 / 满意度"，没拆到"知识库命中率 / 用户首次提问被解决的比率"——这些是过程指标。要补。

### 3. 「不懂行业就不要做新品」—— 选品 / 起名 / 终极形态都要在场景里长出来

- **李文录**："不是先有营销，你一定要先懂行业。" 选品四步法的核心是"B 端和 C 端痛点能不能对上"。
- **唐沐**："我们看到的跨界，那些讲故事的，没踩过坑的，确实很惨。"——因为他们不是从场景出发，而是从"我能造什么"出发。
- **林莹莹**：从 1.0 铺货 → 2.0 产品专业化 → 3.0 场景归类，本质是从"我有什么"转向"用户用什么场景"。
- **戴冬英**："好产品自己会说话。"——节奏从"渠道爆品" → "全域爆品"的前提，是产品本身扎根。

**实操含义**：AI 助手的"场景"目前不够清晰——文档管理中心、智能体、Skill，三者的边界是什么？用户进来第一眼应该看到什么动作？应该按"业务场景"（写一封开发信 / 复盘一个客户）而不是按"工具品类"来组织。

### 4. 「痛点匹配 > 产品描述」—— 不是卖产品，是卖解决方案

- **李文录**最金句："我明明就想买一个产品，但是我从来没有见过一个中国供应商比我还关心我的生意的。"——从 1 台样品 → 100 台 → 500 台×7 万 = 3500 万生意。
- **戴冬英**：从按故事拍 → 按人群拆解（孩子坐 / 上班族坐 / 老人坐），素材做到对位痛点而非对位卖点。
- **林莹莹**：场景化阶段的核心是"你这个问题跟客户的生意直接相关，他一定会回复你"。
- **唐沐**："颜值即正义"对应"情绪价值是用户体验顶点"——好的体验同样要"和用户痛点对齐"。

**实操含义**：培训助手如果只是"列课程"，用户不会来；如果是从"我作为新人，今天该看哪一节"出发，按场景反推课程，体验会完全不一样。培训助手核心场景要重写。

### 5. 「AI 不能上来就全员铺开」—— 找到"最小闭环 / 速胜战"

- **戴冬英**："不是 AI 替代岗位，而是会用 AI 替代很多岗位。"——思路在公司不断重复，"不是一上来就在全公司铺开"，要找最小化单元跑起来再扩展（她选了"设计出图"作为第一闭环）。
- **林莹莹**：AI 出图先在固定产品上跑通，跑通后再扩到其他场景；美工省出来的时间去做"产品研发/客户视角"，就是岗位价值重塑。
- **唐沐**：咖啡机器人先在"封闭咖啡小站"跑通，跑通后才做通用人形——AI 餐饮调酒同理。
- **李文录**：CRM 也先在销售团队跑通，跑通后用过程指标推动全员复制。

**实操含义**：宏昊AI助手如果上线后想全员推广，必须先找一两个标杆业务场景跑通（如外贸开发信、报价单生成），跑通后才横推。"先做对再做大"的次序不能反。

### 6. 「AI 时代要改变的不是给每个岗位加工具，而是把工作看成能力组合」

- **戴冬英**原话："人负责决策判断，AI 执行大量重复工作。"——岗位的边界要变，让员工拓展能力边界。
- **林莹莹**：美工从"按需出图"到"按场景研发（参数具象化、3D 化）"再到"接外单创收"，是同一逻辑。
- **唐沐**："我们去研究一个赛道的时候，如果了解了一下这个行业，就开始动手了。"——跨界不要从零开始，借 AI 抽出"经验"再调用。

**实操含义**：这种岗位能力重塑正是组织变革——AI 小组在公司里的角色不是"工具提供者"，而是"岗位能力工程化"的推动者。这点已经在落地，但表达不够强。后面推动要明确说。

## 五、lw 的整体收获（与外贸 / 采购 / AI 三条业务线）

把 Day1 的 4 讲沉淀后，可以拉出三条业务线对应的"今天以后可以做的事"：

### A. 外贸业务线（ToB 客群）

- B 端开发信 / 客户画像的"五阶段"（破冰→画像→方案→信任→成交）可以直接改造 AI skill，让外贸智能体能走完一整单流程而不只是生成开发信；
- "B 端和 C 端痛点匹配"可以作为外贸选品助手的方法论核心；
- "客户分层：百万/千万/VIP"思路可以借给 shippiing_helper 的客户分级逻辑——目前船务助手是"流程自动化"逻辑而非"客户经营"逻辑。

### B. 采购分析业务线

- "把采购动作拆成关键行为"思路可以给 ProcurementAnalysis 增加"动作看板"模块（每天发起询价次数、跟踪供应商次数、条款评审次数）；
- "永远不要相信第一次需求" → 供应商管理：要主动挖真实诉求；
- "B 端 vs C 端"思路用在供应商画像上：能稳定批量供货的是 B，小作坊式是 C，库存策略应不同。

### C. AI 项目方法论线（宏昊AI助手 / 培训助手 / 数据脱敏）

- Day1 全场共识的"AI 落地六步法"可以提炼成内部培训 / 推广材料：
  1. 找到核心 KPI（李文录的"大客户" / 林莹莹的"订单转化率" / 戴冬英的"中台产能"）
  2. 拆解为关键行为（销售 / 采购 / 客服 / 设计）
  3. 找到最小闭环跑通（戴冬英的"设计出图"）
  4. 把过程指标挂看板（李文录的"24/48/72 小时"）
  5. 复制到平行部门（戴冬英的"中台能力外溢"）
  6. AI 介入后重塑岗位价值（林莹莹的"美工岗位升级"）
- "具体才深刻"——这个六字真言可以作为接下来推动 AI 落地时的口号，比"AI 赋能"这种话实在得多。
