# Claude Code + 前后端 / 数据库粗解培训

**日期**：2026-04-30 ｜ **培训人**：肖聪（AI技术专员） ｜ **学员**：团队组长与组员（多非技术背景） ｜ **工具**：Claude Code、Flask、HTML/JS、Word 文档检索
**来源**：桌面导出《团队与培训/260430前后端+skill》（培训.txt、流程.txt、TestCode 样例工程）

## 一、培训目标与教学理念
让不懂代码的同事在 **40 分钟内**用 AI 编程工具做出一个"能上传 Word、能关键词检索"的小软件，借此吃透**前端 / 后端 / 数据库 / 接口**四个核心概念，建立"不懂代码也能成为开发者"的信心。

核心教学法——**用生活比喻把技术概念翻译成经验**：
- 后端 = 后厨（看不见，但负责"做菜"）
- 前端 = 大堂（看得见，负责点单和展示）
- 接口（API）= 服务员传菜 / 电话线（前后端沟通的通道）
- 数据库 = 用本地文件代替（大公司才用专业数据库）

## 二、四阶段实操流程（可直接复用的教学脚本）

**第一阶段 · 后端搭建（后厨，约15分钟）**
让学员把这段提示词发给 Claude Code：
> 我正在做一个简单的文档检索项目。请你帮我用 Python 的 Flask 框架写一个后端程序 app.py。具体需求如下：需要安装 flask, flask-cors, python-docx 这三个库，请先告诉我安装的终端命令。创建一个 POST 接口 /api/search。该接口接收两个参数：上传的文件（字段名 file）、搜索关键词（字段名 keyword）。后端逻辑：读取上传的 Word 文档全文，检查是否包含该关键词；包含则返回含该关键词的整段文字，不包含则返回"未找到相关内容"。必须配置 flask-cors 允许跨域请求。程序启动在 5000 端口，并打印"后端服务已启动，监听端口 5000"。请直接给出完整代码，并告诉我如何运行它。

验证：终端运行安装命令 → `python app.py` → 出现"监听端口 5000"即成功。

**第二阶段 · 前端搭建（大堂，约10分钟）**
> 后端已准备好（运行在 http://127.0.0.1:5000）。请帮我写一个前端页面 index.html：标题"企业文档智能检索系统"；一个文件选择框（只选 .docx）、一个关键词输入框、一个"开始检索"按钮；下方展示结果区。用原生 JS 的 fetch 把文件和关键词 POST 到 /api/search，成功则显示返回文字，出错则弹提示。给出完整 HTML（含 CSS 和 JS）。

**第三阶段 · 联调与排错（传菜，约10分钟）**
上传测试 docx → 搜文档里**存在的词**（如"年假"）→ 页面显示该段落；搜**不存在的词**（如"外星人"）→ 显示"未找到"。报错本身就是最好的教学机会（见下方救场提示词）。

**第四阶段 · 总结升华（约5分钟）**
前端=网页、后端=Python 程序、数据库=本地文件替代、接口=两者沟通的电话线。点题："不懂代码没关系，只要懂业务逻辑、善用 AI，每个人都能成为开发者。"

## 三、现场救场提示词（报错时让学员问 AI）
- **CORS 跨域报错**（F12 Console 红色报错）：「我的前端请求后端时报了 CORS 跨域错误。请帮我修改后端 Python 代码，加上 flask-cors 配置，允许所有来源请求。」
- **ModuleNotFoundError: No module named 'docx'**：「运行代码报错找不到 docx 模块，请告诉我应该用 pip 安装哪个库？」
- **搜不到内容 / 乱码**：「现在代码读取 Word 文档有问题、搜不到内容。请帮我优化读取 .docx 并提取纯文本的逻辑，确保能准确匹配关键词。」

## 四、防翻车预案（培训前必做）
1. 自己提前跑通一遍，把能跑通的代码存 U 盘 / 云盘。
2. 准备"半成品包"：写好的 `app.py` + `index.html` + 测试用 `测试文档.docx`，直接发给环境搞不定的同事，让其只做第三步"点击搜索"也能体验成功。
3. 电脑卡顿 / 网络连不上时，用半成品包兜底，不打断讲解节奏。

## 五、沉淀：AI 编程教学的四条原则
1. **业务逻辑讲清楚，代码交给 AI**——人负责定义"要什么"，AI 负责"怎么写"。
2. **比喻降低认知门槛**——后厨 / 大堂 / 传菜，比术语好懂十倍。
3. **报错即教学机会**——不回避错误，借机教调试与提问。
4. **提前准备 fallback**——半成品包保证现场不翻车。
