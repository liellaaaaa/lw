# 《干出好结果》· 读书分享

> 分享人：肖聪 ｜ 部门：总经办 ｜ 共 9 次分享（2026-04-23 ~ 2026-06-15）
> 主题脉络：深度工作 → 结果导向 → 整理 → 里程碑 → 学习本质 → 长期方法 → 丛林法则/优势 → 复盘

## 2026-04-23 · 1.1–1.2 深度工作才有价值
- **分享章节**：1.1 及 1.2
- **分享主题**：深度工作才有价值，有价值才有好结果
- **个人收获**：忙碌并不等于有价值，真正的价值在于不可替代性，关键在于手头工作是否能被 AI 或他人轻易取代。深度工作与浅度工作要区分：如果工作仅是浅度工作，个人产出与产出价值都不高；若工作内容确实包含很多浅度工作，其实可以将其流程化、标准化。
- **反思 / 过往错点**：才干了两周，发现 AI 项目已开发好几个，但没有很好的「验收 / 产出 / 测试报告」模板；每次与供应商沟通，也没有专门文档记录发生的问题与解决验证。
- **今后改进**：主动优化工作。

## 2026-04-30 · 1.3–1.5 结果导向
- **分享章节**：1.3~1.5
- **分享主题**：结果导向
- **个人收获**："努力"的标准——书中"方向不对，努力白费"。作为 AI 技术工程师（虽然是实习生），真正的努力不是单纯堆砌代码量或加班时长，而是以"AI 系统 / 智能体平稳运行"为最终结果；技术判断力与服务意识在线，努力才有价值。其次，"分类管理"的提效工具：技术工作中应把精力投入开发、复杂 Bug 排查等"一类问题"，对简单重复性维护流程化处理，避免在低价值事务上空耗。书中"华为新人 180 天手册"与现有新人带教有点类似。
- **反思 / 过往错点**：以前执着于相对标准和精细地完成任务，现在应转为"先完成，再完美"的状态。
- **今后改进**：1. 结果导向；2. 对任务分类。

## 2026-05-09 · 2.1–2.3 整理
- **分享章节**：2.1、2.2、2.3
- **分享主题**：整理要效率，整理出价值，整理好信息（强调整理）
- **个人收获**：1. 无论物理空间（办公桌）、数字空间（电脑文件）还是工作流程，整理都能极大减少寻找物品或信息的时间，提升效率。2. 整理能发现新价值——对现有工作、资源和流程的梳理，可以找到优化点，甚至创造新业务。
- **反思 / 过往错点**：桌面和电脑文件杂乱：办公桌和电脑桌面常堆满文件，找某个文件时浪费时间。
- **今后改进**：1. 建立整理习惯：每周固定时间整理办公桌和电脑文件。2. 主动梳理工作流程：对自己负责的工作做全面梳理，尝试用流程图等方式可视化，简化、合并或自动化，发展成新的价值点。

## 2026-05-17 · 2.4–2.6 里程碑管理
- **分享章节**：2.4~2.6
- **分享主题**：里程碑管理
- **个人收获**：结果里程碑是"过程导航仪"——里程碑不是最终结果，而是分解后的关键节点；每个节点对应"时间 + 目标"，能实时检测进度、及时调整路线、避免偏离最终结果。开发中也需不断通过里程碑确定每个模块开发的前后顺序与紧急度；若不能用类似甘特图的方法对整体流程排序，很可能跟最初需求文档无法对应而产生偏移。
- **反思 / 过往错点**：之前做项目只关注最终截止日期，没拆关键节点。上周开发的采购分析助手就没采用里程碑设计，多头并进、以为进度飞快，结果这周需求重提后发现需要大改的地方非常多。因此持续明确和调整里程碑非常必要。
- **今后改进**：将大目标拆分为"时间节点 + 具体目标"的节点；考虑潜在问题，提前预留缓冲时间。

## 2026-05-23 · 3.1–3.2 学习的本质、思维定成败
- **分享章节**：3.1、3.2
- **分享主题**：学习的本质、思维定成败
- **个人收获**：1. 真正有价值的学习是枯燥但长效的，如研读专业书籍、复盘工作流程、深度思考行业趋势。2. 工作不能简单执行，还需在反复中做流程、做记录，最后形成闭环。
- **反思 / 过往错点**：抛弃伪勤奋——大部分"不动手不实践、只是光看"真的很难融入生活与实际工作。
- **今后改进**：1. 书里建议留一部分时间深度复盘或读书（但我大概光速入睡😂）。2. 流程化思维：抽模板、写流程，今后继续践行。

## 2026-05-28 · 3.3–3.6 问题本质 / 有主张地提问 / 学习重点
- **分享章节**：3.3~3.6
- **分享主题**：3.3 问题的本质 ｜ 3.4 有主张地提问 ｜ 3.5 学习不要盲目 ｜ 3.6 学习的重点
- **个人收获**：1. 书中 5WHY 法找问题本源（"为什么不想工作？"到"为什么不自信？"→ 专业能力不足；此法在固定工作流程中相对有效，但容易为了问问题而回答问题）。2. "131 法则"：请示前准备三个方案并说明哪个最好；"GROW"法则：Goals 目标 / Reality 现实 / Options 可选项 / Will 打算怎么做。3. 明确学习目的，为学习而学习效果很差。
- **反思 / 过往错点**：汇报工作缺乏"方案意识"——以前遇拿不准的问题去请示，习惯直接问"这事怎么办？"，把问题抛给上级，既增加领导决策成本，也显得缺乏独立思考。
- **今后改进**：应用"131 法则"提升汇报质量：请示前先思考并列出解决方案、标注各方案优缺点、明确推荐一个最优方案；从"问答题"转为"选择题"，像 plan mode 一样提供带优劣的选项。

## 2026-06-06 · 第四篇 创造好结果的长期方法
- **分享章节**：第四篇
- **分享主题**：创造好结果的长期方法
- **个人收获**：1. 创造好结果的条件：a. 一万小时练习；b. 正确方法（行业大牛、权威书籍、网络搜索）；c. 练习要有反馈、即时激励，有量有质。2. 经验主义不可取，决断前先反对、找出理由反驳自己，判断是否站得住脚。3. 害怕失去会导致失去更多。4. 找到关键点、关注重点工作（擒贼先擒王）。5. 定期问责——"责"是责任而非责备，责任是否落实、是否完成对他人的承诺。
- **反思 / 过往错点**：1. 工作存在经验主义，总沿用旧流程 / 方法 / 技能，导致程序质量不尽人意。2. 闭环思维弱，没有定期问责、自己问自己每个阶段 / 时间点是否完成了某些工作。
- **今后改进**：1. 突破经验主义，新程序 / 新流程用新思维看待，不固步自封，多从网络多方获取更优路线。2. 仔细罗列日报内容，完成项 / 未完成项都要有明确终止节点。

## 2026-06-14 · 5.1–5.3 丛林法则下聚焦优势与长期规划
- **分享章节**：5.1、5.2、5.3
- **分享主题**：在丛林法则下聚焦优势与长期规划
- **个人收获**：1. 职场规则已从按部就班的"竞技法则"转为优胜劣汰的"丛林法则"。2. 专注 / 学习"森蚺的仁爱"，能熬、主动连接更高圈层的人，打破固有认知。3. 工作成就感来源于做擅长的事，在感兴趣或擅长的事上向外输出或向内深化能获更高成就感。
- **反思 / 过往错点**：1. 什么都想做、什么都没做精，对事项优先级和排期没太好管理，总想面面俱到却无法尽心完成一件事。2. 过去总觉哪里不行就补哪里，花大量时间在非核心技能上，像写程序总被非必要或待优化部分吸引，忘了原本计划是修复 bug 或实现功能。
- **今后改进**：1. 虽没有五年计划，但用长远计划反推各节点是日常有效的方法。2. 主动连接更高圈层（更有技术）的人，打破固有认知，并向小组成员转述，验证自己是否真的学进去了。

## 2026-06-15 · 5.4–5.6 复盘
- **分享章节**：5.4-5.6
- **分享主题**：复盘——让结果更好，厉害的自己
- **个人收获**：1. 复盘四步法：回顾目标（低谷 / 上升 / 平稳期，前提、环境、条件不同，目标不同，需不断复盘纠偏）；评估结果（对照目标：是否达成 / 什么情况下达成 / 怎么达成）；分析原因；总结经验（复盘书：回顾目标、结果对比、分析原因〔过程 / 自我剖析 / 众人设问〕、成功 / 待改进 / 总结、佐证、归档）。2. 复盘关键在及时、迅速、有效、反复，持续进步。3. 错误是支出，支出就有回报（换路或排错）。4. 小步快跑，摸得着的成就感。
- **反思 / 过往错点**：1. 以往处理完紧急任务或项目后，常认为"事情结束"就是终点，没按四步法深度回溯，导致小失误（流程衔接不畅、沟通信息遗漏）虽当时解决却未沉淀，下次仍可能踩坑。2. 对待错误的"止损"心态不够成熟——偏差时第一反应是焦虑或急于掩盖，而非视作"支出"换取经验；一直出错真的很搞心态。
- **今后改进**：1. 复盘：日复盘、周复盘、月复盘。2. 不要怕错，错了也是在成长。
