# 《赢销铁军》· 读书分享

> 分享人：肖聪 ｜ 部门：总经办 ｜ 岗位：AI 技术专员 ｜ 共 3 次分享（2026-06-16 ~ 2026-06-19）
> 主题脉络：战役导向 → 战役要素（天 / 地 / 人） → 战役模式（征峰大决战 / 闪电攻坚战）

## 2026-06-16 · 第1章 战役导向
- **分享章节**：第1章
- **章节主题**：战役导向
- **个人收获**："导向"比"努力"更重要，资源永远有限，没方向的忙就是消耗战。作为总经办新人，以前接到任务第一反应是"立刻做、做完交差"，这本书教我先问"这是哪种导向的仗"：战略级三步走，增长级分持续性还是突破性，业务需求喊的"问题"背后都是没炸开的卡点，头痛医头没用，病根还在。
- **过往错点**：刚进总经办时，会议纪要、各种沟通记录都较详尽，交办的事立刻办，看起来很"努力"，其实是在书里说的"不打仗"模式里耗时间。不理解 AI 小组实际的期待值，做的是按部就班的活，能力没长进，对我没记忆点。
- **今后改进**：事先问一句"这件事对应公司哪种导向的战役？"——能判断战略、增长、卡点哪一种，就知道优先级和该投入多少精力。80% 时间砸在 20% 战略级事务上，其余走标准化流程；做完旧复盘，看自己是不是在打"无导向之战"。

## 2026-06-18 · 第2章 战役要素
- **分享章节**：第2章
- **章节主题**：战役要素
- **个人收获**：决定战役胜负三大关键要素——天（天时）、地（战场）、人（人和）。天回答"什么时候打"：选对时机（避实击虚）、把控节奏（有缓有急）、创造节点（无中生有）；地回答"在哪里打"：察需求浓度 / 竞争烈度 / 资源匹配度，再少而精选地，无中生有造地；人回答"靠谁打"：把"一群人"激活成"一支铁军"。三者环环相扣，缺一个都打不赢。第1章讲"为什么而战"（战略导向），第2章讲"怎么战能赢"；想做成一件事，背后都是一场小战役，都离不开时机、战场、人心（天地人），原本混乱的工作有了"作战地图"的感觉。
- **过往错点**：最开始接需求要找相关人员，联系对方时已经下班或出差，错过窗口。发现自己既没算"天"（重要的事不能拖到临近下班找别人），也没识"地"（这事该优先跑哪一环），更没借"人"（可以让同事或 AI、记事本预警自己）。
- **今后改进**：今后每件事开工前，先用"天、地、人"过一遍：天——什么时机、什么节奏、卡什么节点；地——做给谁、走哪条路径、聚焦什么环节；人——谁推动、谁兜底。三要素齐了动手，缺哪个提前补哪个。

## 2026-06-19 · 第3章 战役模式
- **分享章节**：第3章
- **章节主题**：战役模式
- **个人收获**：第一、二章讲"为什么打""用什么打"，本章讲"怎么打能赢"，给两种战役模式：① 征峰大决战（战略 + 增长导向），按"年季月周"四峰和十二月十二战体系，从"懂 / 拆 / 落"三年战略分析到季度攻坚、月度积累，集中兵力打硬仗（长线作战）；② 闪电攻坚战，用"四三法则"（标准 / 动作 / 流程 / 时间四个重构 + 极速 / 借力 / 集火三把尖刀）。一个长线、一个速胜。
- **过往错点**：日常事务没把事务当成战役设计，没给自己设硬性节点（什么时间出材料、什么节点确认），结果临场被动、反复救火。
- **今后改进**：做事事先用"四峰十二战 + 闪电攻坚"的镜头过一遍：这是日常事务还是长期战役？要长期主义还是速胜主义？定好目标、节点、节奏、负责人，到点交、不拖延、不内耗。
