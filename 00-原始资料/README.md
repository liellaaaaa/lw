# 00-原始资料

这里是你往知识库里"喂"材料的地方。**原始资料不用先整理，先放进来。**

## 可以放什么

- **文章**：看到的好文、长文截图或正文
- **视频逐字稿**：B 站 / YouTube / 播客的逐字稿或转写
- **课程笔记**：培训班、网课、讲座的零散记录
- **读书摘录**：书里的划线和摘抄
- **聊天记录**：有价值的对话、群聊精华、咨询记录
- **灵感**：突然冒出来的想法、碎片念头
- **网页摘录**：收藏夹里吃灰的链接、剪藏内容

## 使用提醒

- 不用分类、不用改名、不用排版，能丢进来就是进步。
- 文件名随意，后面让 AI 在消化阶段再帮你归类。
- 真材料优先于漂亮结构。先有一份真实资料跑通流程，再谈优化。
