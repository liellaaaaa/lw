# 周报 / 日报消化提示词（肖聪 · 个性化版）

> 用途：`00-原始资料/` 下的周报、日报 → `01-AI消化笔记/`（也可直接作为 `04-复盘/` 素材）。
> 用法：把整段发给 AI，指定具体某篇周报 / 日报。

---

## 指令

读取指定周报 / 日报，提炼成消化笔记。重点**不是复述"做了什么"，而是"学到了什么、能复用什么"**。结构：

1. **本周 / 本日一句话总结**
2. **做了哪些事**（极简罗列）
3. **踩了哪些坑 / 解决了哪些问题**（提炼出可复用的方法）
4. **对我（AI 技术专员）的能力或认知有什么提升**
5. **能变成什么输出或选题**
6. **下一步动作**

提示：
- 周报消化后，可直接作为 `04-复盘/` 的素材；若发现可写成文章的点，标注**建议标题**。
- 关注与宏昊AI助手、ai-sales-coach 相关的进展，优先消化这部分。
