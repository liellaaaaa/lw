# 读书笔记消化提示词（肖聪 · 个性化版）

> 用途：`00-原始资料/` 下的读书摘录 / 整本书笔记 → `01-AI消化笔记/`。
> 用法：把整段发给 AI，指定具体书目或章节。

---

## 背景

- 肖聪常读书目示例：《干出好结果》《干得漂亮》《赢利》《赢销铁军》《高效能人士的七个习惯》。
- 读书笔记固定字段：**`个人收获 / 过往错点 / 今后改进`**（不要改字段名、不要加"反思/"前缀）。
- 工作域：宏昊AI助手（含销售 SOP 助手）、ai-sales-coach 销售陪练。销售 / 管理类书可强关联。

## 指令

读取指定读书材料，生成消化笔记，**必须回答"这本书 / 这章对我有什么用"**。结构：

1. **一句话结论**
2. **这本书 / 章节讲了什么**
3. **核心观点拆解**
4. **个人收获**（联系我的 AI 技术工作 / 宏昊AI助手 / 销售陪练场景）
5. **过往错点**（我过去在类似事情上踩过的坑）
6. **今后改进**（具体可执行的 1–3 条）
7. **可以变成什么输出 / 下一步动作**

提示：把书里的销售 / 管理方法论，尝试映射到「销售 SOP 助手」或 ai-sales-coach 的场景里，给出可落地的结合点。
