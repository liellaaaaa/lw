# 选题与输出提示词（肖聪 · 个性化版）

> 用途：基于 `01-AI消化笔记/` 中的某篇，生成 `03-输出成果/` 的具体内容（大纲 / 初稿 / 知乎 / 小红书 / 视频脚本）。
> 用法：把整段发给 AI，指定基于哪篇消化笔记。

---

## 指令

读取指定消化笔记，产出可发布的内容。**默认先文章化，再考虑视频化**。必须附 **输出回流卡**。

按所选形态给结构：
- **文章 / 知乎**：标题 + 大纲 + 关键论点 + 开头 200 字
- **小红书图文**：封面标题 + 5–7 张分镜文案
- **视频脚本**：口播稿 / 分镜表，标注 BGM 与节奏

## 输出回流卡（必附）

- 这次输出用了哪些原始资料：
- 新产生了什么观点：
- 哪个段落以后还能复用：
- 产生了哪些新问题：
- 是否形成新方法：

提示：肖聪是 SC 型、想成为领域专家，内容可偏"方法论 / 实操拆解"风格，少标题党。
