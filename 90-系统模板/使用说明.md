# 知识库使用说明

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-收件箱/` | 待整理内容入口，临时存放 |
| `01-每日记录/` | 按日期的工作记录 |
| `10-项目/` | 有明确目标和结束条件的项目 |
| `20-知识/` | 可长期复用的方法、规则、经验 |
| `90-系统模板/` | 使用说明、AI规则、模板、初始化记录 |
| `99-归档/` | 已结束或不再使用的内容 |
| `附件/` | Markdown 笔记引用的辅助文件 |

## 常用自然语言操作

| 你说 | AI 做什么 |
|---|---|
| **"记一下：……"** | 记录到当天每日记录 |
| **"加入收件箱：……"** | 保存为待整理内容 |
| **"建立一个项目：……"** | 创建项目笔记 |
| **"更新项目：……"** | 更新项目状态、决策或下一步 |
| **"把这段整理成知识笔记"** | 先提出整理和去向建议，确认后写入 |
| **"查一下……，并列出来源"** | 只读检索并说明实际使用的笔记 |
| **"整理最近一周"** | 汇总每日记录、处理收件箱并提出知识沉淀建议 |
| **"归档……"** | 先展示归档对象和影响，确认后移动到归档 |

## 文件命名规范

- 每日记录：`YYYY-MM-DD.md`
- 项目笔记：使用具体事项名称，不用"新项目""项目1"等空泛名称
- 知识笔记：优先用"解决什么问题"或"什么方法"方式命名

## YAML 属性

普通笔记只使用：
- `created` — 创建日期
- `updated` — 更新日期
- `tags` — 标签

项目笔记额外使用：
- `status` — 当前状态
