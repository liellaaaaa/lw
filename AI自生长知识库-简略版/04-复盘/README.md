# 04-复盘

这里**每周记录一次**，让知识库闭环、并暴露出哪里卡住了。

## 每周回答这五个问题

- **本周放进来了哪些资料**：列 `00-原始资料/` 新增的材料。
- **哪些资料真的被消化了**：对照 `01-AI消化笔记/`，没消化的要诚实标出来。
- **哪些内容产出了文章或笔记**：对照 `03-输出成果/`，写出具体成果。
- **哪个环节最有用**：是"丢资料"爽，还是"消化笔记"开窍，还是"复盘"最提效？找到你的杠杆点。
- **下周只推进哪三件事**：克制。只挑三件最值得推进的，避免贪多烂尾。

## 文件名建议

`复盘-YYYY-Www.md`（如 `复盘-2026-W31.md`），按周归档。
