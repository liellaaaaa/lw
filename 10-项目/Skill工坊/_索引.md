## 管理约定

1. **归属标准（2026-09-10 用户确认）**：纯 Skill 项目（无独立代码仓库）一律收进工坊——不管有没有需求方；独立代码仓库项目（如 Tax_check 的 FastAPI 应用）留在 `10-项目/` 根目录，工坊只放其 Skill 形态的档案并互链。
2. 新 Skill 诞生：运行位落包 → 本表加一行 + 建同名深度档案（结论先行：定位/业务口径/机制/踩坑/时间线/下一步）→ 有独立需求方的在工坊内建完整项目文件夹（主文件+项目日志）。
3. Skill 状态变化（交付/改版/废弃）：更新本表对应行 + 档案的「进度时间线」与「下一步」，不重复建档。
4. 项目档案与 Skill 的对应关系：Skill 是交付形态，项目档案记业务线（需求方/时间线/提效量化），两者靠 `skill_path` 与本表互链。
