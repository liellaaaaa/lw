# resume-screening（简历筛选与人才评估）

**日期**：2026-09-10 归档

> **一句话**：一批简历 + 目标岗位画像 → 硬门槛核查 → 八维加权证据制评分 → 胜任度等级定位 → 排序总表 + 面试追问，必出自包含 HTML 报告。

## 定位与核心纪律

- 服务招聘决策但**不替决策**：只出建议（推荐面试/待定/不推荐）+ 理由，决定权留给人事。
- **证据制是灵魂**：每维打分必须引用简历原文关键句，没写就是「未体现（0 档）」——禁止正向推测（「会 Python 大概率会 SQL」）也禁止负向推测（转行经历少 ≠ 能力差）。每项结论可追溯回简历段落。
- **反歧视红线**：年龄/性别/婚育/户籍/籍贯/照片/第一学历出身一律不评分，读到也忽略。
- **存疑不否决**：门槛信息不全标「存疑」进面试追问，不直接淘汰；解析失败的文件标注上报，不跳过不报。

## 评分体系

- 八维加权：档位 4(充分胜任)~0(未体现)，总分 = Σ(档位÷4×权重)×100。
- 胜任度定位表述法：**「低一级标准完全满足 + 高一级标准部分满足」**（如「满足初级，接近中级（RAG 工程化证据充分，量化评估与 CI/CD 证据不足）」），定位依据成果业绩证据而非技能罗列。
- 默认建议线：≥70 推荐面试 / 55-69 或门槛存疑待定 / <55 或门槛不通过不推荐（用户有紧迫度/预算约束时按其口径调并注明）。
- 面试追问 3-5 条优先覆盖：存疑项 + 高分维度深度验证。

## 岗位画像机制

- 内置「AI技术专员」画像（本科+/计算机相关专业/1 年+ AI 应用或数据开发经验，八维权重表 + 五级胜任度标准）。
- **可泛化**：给公司标准《岗位职责+胜任度》xlsx 即可解析出新岗位画像（岗位职责 sheet：基本条件/应知/应会/关键行为能力；胜任度 sheet：分级标准），解析后先与用户确认硬门槛与权重再开筛。
- 无标准表时按 JD 文本自建画像并确认。
