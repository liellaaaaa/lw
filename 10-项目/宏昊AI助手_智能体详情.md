# 宏昊AI助手 · 智能体详情

## 一、工艺流程助手

- **定位**：染整行业技术问题诊断与排查
- **目标用户**：销售 / 业务人员
- **核心能力**：基于《印染工艺知识手册》（10 章）回答工艺问题

### 知识库

| 章 | 内容 |
|---|---|
| 第 1 章 | 染整工业概述（烧毛→退浆→煮练→漂白→丝光） |
| 第 2 章 | 染色基础原理（染料分类、上染过程、色牢度） |
| 第 3 章 | 印花工艺（平网/圆网/数码印花） |
| 第 4 章 | 后整理工艺（柔软/防水/阻燃/抗菌整理） |
| 第 5 章 | 常见疵病与排查（色花/色差/白斑/黄变等 20+ 种） |
| 第 6 章 | 助剂选用指南（前处理剂/匀染剂/固色剂/硅油等） |
| 第 7 章 | 品质检测与标准（AATCC、ISO、GB 等） |
| 第 8 章 | 环保与安全（废水处理、REACH、OEKO-TEX） |
| 第 9 章 | 常见客户问题与应对（终端品牌常见投诉） |
| 第 10 章 | 附录（术语表、快速索引） |

### 培训资料

6 个研发部门的清洗版培训资料：前处理 / 固色剂 / 硅油 / 湿摩擦 / 日化 / 后整理

## 二、说明书助手

- **定位**：产品技术说明书 (TDS) 查询与解读
- **目标用户**：销售 / 业务人员
- **提示词规模**：16 节完整结构化提示词

### 6 大模式

| 模式 | 功能 |
|---|---|
| 产品查询 | 按产品名称/编号精确定位，返回完整 TDS 信息 |
| 产品推荐 | 根据客户需求（面料/工艺/效果）推荐合适产品 |
| 产品对比 | 同类产品横向对比，突出差异与选型建议 |
| 工艺指导 | 针对产品给出推荐工艺参数与操作要点 |
| 客户场景分析 | 根据客户实际生产场景匹配产品方案 |
| 文件索取 | 提供 TDS / MSDS 等文档下载指引 |

### 关键设计

- 强制信息充分性检查（信息不足时反问澄清，不猜测）
- 结构化输出（适用范围 → 推荐工艺 → 注意事项 → 替代方案）
- 关联产品自动推荐

## 三、销售 SOP 助手

- **定位**：销售标准操作流程引导
- **知识来源**：7 份 SOP 源文件

### 知识覆盖

| SOP 文件 | 内容 |
|---|---|
| 公司概况 | 企业介绍、规模、核心优势 |
| 行业术语 | 染整行业专业术语库 |
| 产品知识 | 各产品线核心卖点与适用场景 |
| 技术问题 FAQ | 客户常见技术疑问应答 |
| 抗拒点应对 | 客户常见拒绝理由及应对话术 |
| 竞品分析 | 主要竞争对手对比 |
| 新客开发 | 新客户开发流程与话术 |

### 触发场景（6 个）

1. 客户询价 → 标准报价流程
2. 技术咨询 → 转接 + 初步解答
3. 客户投诉 → 安抚 + 记录 + 升级
4. 新客接触 → 破冰 + 需求挖掘
5. 老客维护 → 定期回访 + 新品推荐
6. 竞品对比 → 优势分析 + 差异化话术

### 提示词迭代

- 存在「当前提示词」与「新提示词」两个版本
- 新提示词为待替换版本，结构更精简

## 四、业务智能助手 (customer-issue-advisor)

- **定位**：客户问题处理全流程 AI 助手
- **项目代号**：customer-issue-advisor
- **文件结构**：SKILL.md + references/（templates.md, role-playbooks.md）

### 三阶段工作流

```
客户问题输入
    ↓
阶段一：问题梳理（诊断根因 + 归类）
    ↓
阶段二：说明书查询（自动检索相关 TDS）
    ↓
阶段三：客户回复 + 行动建议 + 风险提醒
```

### 4 种岗位自适应

| 角色 | 输出侧重 |
|---|---|
| 业务人员 | 简化技术术语，突出卖点与话术，直接可用于客户沟通 |
| 应用工程师 | 深度技术分析，工艺参数建议，实验方案 |
| 部门负责人 | 资源协调建议，风险管控，决策框架 |
| 部门助理 | 任务清单化，流程化指引，便于分发执行 |

### 输出规范

- **措辞红线**：禁止绝对承诺（"一定""保证"等），禁止贬低竞品，禁止透露成本
- **模板库**：客户回复模板 / 内部行动清单模板 / 风险评估矩阵
- **迭代历程**：经历多次版本迭代（0712 最终提示词 → 0713 最终提示词 v5 等）
