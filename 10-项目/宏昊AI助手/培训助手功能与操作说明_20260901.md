# 培训助手 · 功能全景与操作说明（2026-09-01）

**日期**：2026-09-01（下午，公司培训助手实操培训现场）
**来源**：企微会议转写稿（前半场 刘妍妍 产品介绍，后半场 肖聪 带教实操，末尾 李文婷 宣讲考核规则）
**用途**：平替酷学院的内部培训平台。9 月起内测，全员开号，考核从酷学院平移过来。

> 背景：本模块仍挂在 [[宏昊AI助手]] 供应商平台下（后台不迁移），但企微端已独立出「培训助手」应用与 bot。方案沿革见 [[培训助手轻量迁移方案_20260808]]；现场暴露的系统问题见 [[2609_HH问题反馈汇总]]。

---

## 一、定位与入口

培训助手要解决的不是"有没有课"，而是**培训这条链路上每个节点都要人推**的问题。原来的六个痛点：资料分散难跨部门复用 / 部分环节依赖人工执行 / 缺考试无法验证掌握程度 / 学习进度不透明 / 员工任务不清易逾期 / 数据不集中复盘无依据——共性都是"人推"。现在把整条链路放进系统，由流程推人。

**企微入口（三个，别混）**

| 入口 | 位置 | 作用 |
|---|---|---|
| 宏昊AI助手 | 工作台 | **管理员后台**：文件管理、生成试题、创建/发布计划、通知下发、看报表 |
| 培训助手（应用） | 工作台 / 企微搜索 | **学员端**：黄衣小人图标，看必修、选修、个人学时与考试情况 |
| 培训助手（应用提醒） | 企微消息列表 | **bot**：只用于接收通知卡片与每周提醒，点进去是对话框 |

⚠️ 企微搜索"培训助手"会出现**两个同名项**：一个是"应用提醒"（bot，只收信息），一个是"应用"（点进去进学习页）。现场发现部分同事只有"应用"、没有"应用提醒"，收不到推送——已反馈。

**后台路径**：工作台 → 宏昊AI助手 → 点头像 → 知识中台 → **文档管理中心**（文件与试题都在这）
**计划路径**：工作台 → 宏昊AI助手 → 培训中心 → **培训管理**（计划、通知、报表都在这）

手机端能看个人学习，不能操作；部门报表必须回电脑端后台。

---

## 二、三类角色与权限

| 角色 | 权限范围 | 谁在用 |
|---|---|---|
| 系统管理员 | 最高权限。可看所有部门的培训计划、学习进度、考试结果；跨部门培训支持 | 培训主管 李文婷；肖聪（技术） |
| 部门培训管理员 | 本部门任务的创建、发布、结果管理；**只能看到自己部门** | 各部门对接人（本次培训对象） |
| 员工本人 | 接收任务、学习、考试、查看个人学习情况 | 全员（含一线生产、业务员、研发） |

跨部门培训需联系培训主管开通；权限只开到本部门，看不到别的部门数据。

---

## 三、培训链路九节点

| # | 节点 | 执行人 |
|---|---|---|
| 1 | 选择培训资料 | 管理员 |
| 2 | 生成考试试题 | 管理员 |
| 3 | 创建培训计划 | 管理员 |
| 4 | 发布培训任务 | 管理员 |
| 5 | 发送企业微信通知 | 管理员（**1–5 全是管理员准备动作**） |
| 6 | 学员查看、学习 | 学员 |
| 7 | 学员考试 + AI 答疑 | 学员 |
| 8 | 学员看个人情况 / 管理员看部门数据 | 双方 |
| 9 | 归档（错误或需撤回的计划） | 管理员 |

关键认知：**第 5 节点是分界线**。计划没发通知，学员手里就什么都没有；创建 ≠ 发布 ≠ 通知，是三个动作。

## 四、六大核心功能（管理员侧）

### 功能 1 · 培训资料管理

文档管理中心 = 左文件夹树 + 右文件列表。两种资料来源：

- **本部门文件夹**：自行上传，部门资料沉淀在这
- **宏昊学院**（公共知识库）：2000+ 门课程，含 AI 类、管理类、领导类、个人成长类、电子书等，可按需下发本部门员工

批量操作：勾选文件前的复选框 → 移动 / 删除 / 批量下载 / 批量不允许下载 / **批量生成试题**。

### 功能 2 · AI 生成试题

- 一键生成，题数预设 10/25…，可选 **10–100 题，必须是 5 的倍数**（10 / 15 / 20 / 25…）
- 生成需等 1–2 分钟；生成中不能查看，完成后按钮变为「重新生成」+「查看试题」
- 试题可编辑：题干、选项、提示、正确答案都能改，改完保存
- **试题与文档绑定**：文档管理中心里生成成什么样，学员端考试就是什么样。下发后发现题错了，学员端改不了，只能回文档中心改、再把计划复制一份重发
- **AI 出的是初稿，必须人工过一遍才能用**（2000 多门课人工审不过来，下发后发现错题请截图反馈）

**出题的格式限制（现场踩坑重点）**

| 格式 | 是否支持出题 | 说明 |
|---|---|---|
| mp4 / mp3 | ✅ | 提取音频转文字，基于文字出题 |
| 文字版 PDF / docx | ✅ | 需 **≥1000 字**，字数不够出不了那么多题 |
| PPT / doc | ❌ | 需先转 PDF 或 docx |
| 纯图片型 PDF / Word | ❌ | 识别失败，需先 OCR 成文字版文档 |
| Excel | ❌ | 不支持 |

> 现场争议：流程类文件普遍不足 1000 字，出不了 10 道题。文婷要求技术侧先解决字数限制，再谈题数。

### 功能 3 · 创建 + 发布培训计划

**两步走：保存 = 草稿（可编辑）→ 发布 = 已发布（不可编辑）。只有已发布，通知按钮才会变亮可点。**

新建计划字段说明（培训中心 → 培训管理 → 新建计划）：

| 字段 | 说明 |
|---|---|
| 计划名称 | 定义在企微通知的第一行"培训通知"下方。建议命名：`部门 + 月份 + 培训计划` 或课程课题 |
| 描述 | 选填（现场反馈下发后描述可能不显示） |
| 所属部门 | 只能选到自己有管理权限的部门 |
| 建议完成天数 | 提示性质，不强制 |
| 截止方式 | **固定截止时间**：到点所有人不能再学 / **按学习天数**：从下发当天起算，灵活（1 号发、2 天 → 3 号截止；5 号发 → 7 号截止） |
| 默认时长要求 | 文档类必须设"最少阅读几分钟"才算完成，**不设则点进去退出就算完成**（苹果手机尤其明显）。单位分钟。**视频不用设**，后台按实际时长自动识别 |
| 学习文件 | 从本部门文件夹或宏昊学院勾选，可对每个文件单独设时长、可上下调整顺序 |
| 学习要求 | **学习 + 考试都完成**：看完 + 考试 ≥80 分，该文件才算完成 / **只考试**：适用于外训或内训已讲过、只需考核的场景，播放时长不影响完成进度 |

计划列表能看到：计划名称、所属部门、状态、文件数量、**发送次数**（= 已下发给多少人，为 0 即未下发）。

**发布后发现错了怎么办**：不能改。用「复制」生成副本（名称后带"副本"字样），改完再发布。⚠️ 现场发现复制后改名不覆盖、仍显示旧名——已反馈。

### 功能 4 · 企微通知下发

培训管理 → 通知 → 默认"企业微信通知" → 选部门 → 勾选人员 → 确认发送。

- 已推送过的人**不能重复推送**
- 自定义消息可不管
- 学员端企微收到黄衣小人卡片，点进去直达学习页
- 下发即产生待办，**不归档就会一直躺在学员的提醒里**，下发前想清楚

### 功能 5 · 学员学习与考试（学员侧）

- **学习**：点开文件预览，系统计时，看满设定分钟才算完成
- **考试**：题目即文档管理中心生成的那套，**合格线 80 分**（100 题对 80，10 题对 8）
- 未达标：可关闭或重新考试；「明细或答疑」里看错选了什么、正确是什么、为什么错为什么对
- **答疑助手**：对话式 AI，可以直接问"第三题为什么选 A"，它会基于文档/视频内容解析
- **补考**：不合格的课程卡片上有「补考」按钮，**不限次数，可考到合格为止**
- **每周一 09:00 左右推送"每周学习提醒"**：本周需完成 / 已完成 / 未学习 / 逾期，点进去是个人学习情况。已完成的人不会收到——不用管理员天天催

**个人学习看板**（培训助手应用内）：

- 上半区**必修学习**：管理员下发的所有计划都算必修
- 下半区**宏昊学院**：选修，自由学，**时长同样计入月度学时**
- 右上角个人学习情况：总学时、按年/季/月筛选，下方是考试情况

### 功能 6 · 数据追踪与导出

| 报表 | 位置 | 看什么 |
|---|---|---|
| 单个计划报表 | 培训管理 → 计划「更多」→ 报表 | 该计划下每个文件：谁看了多久、要求多久、是否达标、发送给了谁 |
| 总培训数据报表 | 培训中心 → 总培训报表 | 本部门所有计划汇总，按部门/人员/时间筛选，查看次数、学时 |

⚠️ **公司维度的数据目前有误**，部门和个人维度的数据是正确的。

**归档**：更多 → 归档。用于建错的、需撤回的计划。归档后学员端该计划消失、不能再学再考，**不可逆**，不支持重新编辑再发布——只能重发一个新的。

## 五、9 月起考核规则（李文婷现场宣讲）

| 项 | 规则 |
|---|---|
| 账号 | 全员开通（含一线生产、业务员、研发、实习生）。酷学院只有 220 个账号、约 100 元/人/年，覆盖不全 |
| 酷学院 | 9 月内测成功后**不再续费**；已下发的酷学院计划可用到今年年底 |
| 月度学时 | 员工级 **3 小时**、主管级 **2 小时**、经理级 **1 小时** |
| 口径 | 必修 + 选修**合计**达标即可；但**必修必须先学完**（必修会归档、会逾期）。经理学完 1 小时即使课程未全部完成，学时也计入 |
| 下发要求 | 部门培训管理员每月至少给员工级下发 3 个学时 |
| 新人 | 必须完成新人学习包，**完成度 ≥80% 且考试通过率 ≥80% 才允许转正**，否则延期直至达标。本人后台可见完成度与通过率 |
| 考试通过率 | 各部门考试通过率纳入季度 PPT 公示排名 |
| 考核 | 不学习名单提前报备李文婷并说明原因；不达标暂沿用酷学院规则：100 元 / 部门 / 培训管理员（9 月，后续评估调整） |
| 内测期 | 9 月为内测，出问题**截图 / 录屏**给妍妍或肖聪，快速修 |

**课后作业**：9 月 4 日（周五）前，各部门完成本部门人员 9 月培训计划下发；后台会看下发完成情况，月底验收学时。
